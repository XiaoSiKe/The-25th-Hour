# 结局与成长成就系统

## 基本规则

结算后统一进入 `结局与成就` 页面，页签固定为：

- 人生结局
- 成长成就
- 排行榜

当前内容量以本文件总库表格为准，不设置固定数量上限。新增或删除条目时，应同步保证每条记录都有 `标题 / 内容 / 触发条件 / 分数`。

结局与成就均计入独立图鉴。人生结局首次解锁时按表格计分；同一人生结局重复达成时，只有前 `2` 次重复达成各计入 `50` 分；从第 `3` 次重复达成起，只记录达成次数，`scoreAwarded = 0`，不再增加排行榜分数。成长成就全局只计分一次，单局内也不重复弹窗；之后再次满足条件不再弹窗，也不再重复计分。

累计条件默认读取跨局累计：凡触发条件只写 `累计` 或 `游戏中累计`，均读取已完结历史局 + 当前局的累计值；凡明确写 `单局累计`，只读取当前局。当前局内达成的成长成就可以即时提示，但只有本局达成人生结局后才写入跨局图鉴和排行榜分数。玩家中途放弃学业并重新开始时，只删除当下该局的本地存档，不删除之前的存档或已提交到图鉴的跨局记录；当下该局的所有记录都会删除，不写入跨局记录，本局已经提示过但尚未随人生结局提交的成长成就、累计次数和排行榜分数全部作废。

`结局与成就` 弹窗摘要区必须展示累计规则：

1. 结局分数与成就分数共同计入玩家排行榜总分。
2. 同一人生结局重复达成的前 `2` 次按 `50` 分计入排行榜；第 `3` 次及以后仅记录达成次数，不再增加分数。

## 成就提示

成长成就在游戏过程中即时触发。

- 达成条件后尽快显示成就提示，但不使用阻塞弹窗。
- 成就提示在界面右上角自动出现，单条提示约停留 `3.9` 秒后自动消失；提示框最终宽度为 `438px` 上限、相对上一版缩小 `10pt`，内容区同步收紧右侧留白并保持标题、内容和分数可读。
- 提示显示：成就标题、成就内容、获得分数。
- 成就首次解锁同时写入日志框的 `成就日志` 分类；成就解锁记录不混入 `行动日志` 或 `事件日志`。
- 成就提示不打断结算、评图、路线选择等关键流程；若正在关键流程中，则延后到该流程结束后依次以右上角提示显示。
- 成就提示表示“本局已达成”；本局达成人生结局后，才永久收录进成长成就图鉴。
- 同一成就本局和历史图鉴内均不重复触发；已收录的成长成就再次达成不弹窗、不加分。
- 人生结局首次收录时可以显示右上角 `结局达成` 提示；同一人生结局已收录后，重复达成不再显示右上角结局提示，即使该次重复达成仍处于前 `2` 次重复计分范围内。
- 涉及同周连续行动或行动完成类单局累计次数的成就，在周结算完成后统一判定。
- 行动完成类的累计次数按触发条件文字读取：写 `单局累计` 只读当前局；只写 `累计` 或 `游戏中累计` 读跨局累计。
- 涉及历史游戏的成就读取全局图鉴记录，不只读取当前单局。

## 成就图鉴 UI

- 成长成就图鉴显示全部成就条目。
- 未获得成就显示为灰色锁定态。
- 未获得成就不展示达成条件；内容区域显示锁定占位文案。
- 已获得成就展示标题、内容、触发条件和分数。
- 人生结局图鉴显示全部人生结局条目；每条都展示 `达成次数：N次`，未达成时显示 `达成次数：0次`。

## 分数规则

最高单项分数为 `1000`。

- 结局分数区间：`100-1000`
- 成就分数区间：`10-1000`
- 强路线结局接近高分，普通通关结局保留中低分，失败结局保留少量收集分。
- 成就数值颗粒度按触发难度分层：单周内连续行动 `2 / 3` 次采用 `200 / 400`；行动完成类单局累计的低阶记录采用 `20`，进阶记录采用 `200 / 400`；商店购买类按具体条目区分单局累计或跨局累计，同一成就系列只在同一颗粒度阶梯内递进。

排行榜采用跨局累计口径：

- 排行榜分数 = 已解锁成长成就分 + 已解锁人生结局分 + 重复达成人生结局折算分；作品集总分不计入排行榜分数。
- 成长成就已经触发并收录后，再次达成不重复触发，分数不累加。
- 人生结局已经触发并收录后，前 `2` 次重复达成同一人生结局，每次按 `50` 分低幅累计到重复结局折算分；第 `3` 次及以后重复达成只增加达成次数，重复结局折算分不再增加。
- 失败局也会达成人生结局，因此失败局结算后的本地累计排行榜总分允许提交排行榜。
- 中途放弃学业重新开始时，只删除当下该局的本地存档，不删除之前的存档或已提交到图鉴的跨局记录；当下该局的所有记录都会删除，不写入跨局记录。本局触发但未随人生结局提交的成长成就、累计次数和排行榜分数全部作废，不计入排行榜。
- 排行榜只提交同一 `playerId` 的本地历史最高排行榜总分；重复达成人生结局的 `50` 分已有硬上限：同一人生结局最多 `2` 次重复计分。

## 量化口径

本节只作结局表阅读辅助。流程、阈值、概率以 `systems.md` 和 `numbers.md` 为准。

| 概念 | 口径 |
|---|---|
| 高危状态 | `精力 < 30` 或 `压力 > 80`。 |
| 精力危险线 | `精力 < 30`。 |
| 安全区 | `精力 >= 35` 且 `压力 <= 75`。 |
| 金钱高危 | 当前金钱低于角色家庭背景对应的 `1` 周自动花费。 |
| 普通 / 沉重 | 通关时 `精力 < 35` 或 `压力 > 75` 为沉重，否则为普通。 |
| 正式参与路线 | 只有大五阶段完成对应报名、申请、投递、考试或确认后才形成记录；只满足数值门槛不算正式参与。 |
| 完成毕业设计 | 读取 `systems.md` 的“毕业设计门槛”和 `numbers.md` 的“评图”。 |
| 实习价值 | 普通实习 `+1`，强事务所实习 `+2`，名企实习 `+3`；退出或作废不计入。 |

## 结局读取规则

结局读取优先级从高到低固定为：

1. 任意结算中已经触发中途失败时，立即读取对应失败状态的人生结局，并结束本局。
2. 完整读到大五下但未完成毕业设计时，读取 `毕业失败——你被延毕了！`；若本次同时形成累计第 `2` 次 `F`，仍以本结局为准。该分支在评图结果页将确认按钮显示为 `恭喜你同学，你被延毕了！`，点击后直接进入结局页面，不播放毕业典礼或结尾回忆。
3. 已形成后期路线正式参与记录时，只在该路线和已确认档位、岗位或内部判定结果内读取成功结局或路线回落结局，不跨路线兜底。
4. 未形成后期路线正式参与记录，或没有可读取的方向专属回落结局时，按最终状态读取普通状态毕业结局。

路线成功类结局必须同时满足：

- 玩家完整读完五年，且未触发中途失败。
- 玩家已形成且只形成 `1` 个路线正式参与记录。
- 玩家完成毕业设计；未完成时进入内部 `没毕业` 状态，并读取人生结局 `毕业失败——你被延毕了！`，不读取成功结局。
- 角色数值、作品集、GPA、竞赛、实习、AI 经历等满足该结局触发条件。
- 需要考试或复试的路线，申请/报名门槛以正式参与时通过为准；最终结局只追加读取对应考试或复试分数线。
- 留学申请、建筑工作投递和非创业转行投递必须读取当次锁定的内部判定结果；成功结局读取内部判定成功，回落结局读取内部判定失败。
- 路线入口门槛未满足时只置灰并展示缺失条件，不形成正式参与记录，也不写入路线失败。
- 路线失败原因、概率和内部考试线不向玩家精确展示，只通过结局文本表达结果；调试日志内部保留原因。

如果玩家满足某条路线的数值门槛，但没有在过程中选择该路线，不读取该路线结局。

若玩家毕业前没有正式参与任何后期方向，结局系统跳过路线成功与路线回落结局，只按最终状态读取普通状态毕业结局。

路线相关成就只在报名、申请、投递、考试或确认等正式参与动作完成时触发。

路线互斥规则：

- `保研 / 考研 / 留学 / 选调 / 考公 / 考编 / 建筑工作 / 转行` 每局只能选择一个。
- `选调 / 考公 / 考编` 不能互相串线读取结局；正式参与时还必须锁定 `1` 个具体岗位或岗位层级，并且只能读取该岗位成功结局或对应回落结局。
- `建筑工作` 必须锁定 `1` 个投递岗位，并且只能按当次投递内部判定读取该岗位成功结局或 `求职待定——回去等通知吧！`。
- `转行` 必须锁定具体岗位，并且只能按当次投递内部判定读取该岗位成功结局或 `转行失败——转行可不是那么容易的！`。
- `创业` 是 `转行` 下的特殊岗位入口，只有六项角色属性全部 `>= 80` 时可选；满足后弹出 `恶魔的契约` 二选一弹窗，签下契约立即形成路线正式参与记录并锁定读取 `没有退路的选择——一条最孤独之路`，不再弹出路线确认或等待结果提示；选择放弃等同于取消本次选择，不锁定路线。

创业契约弹窗：

| 标题 | 内容 | 选项 |
|---|---|---|
| 恶魔的契约 | 现在有一份恶魔契约摆在你的面前，如果签下，你可以拥有无限的心力与精力；但代价是，无论多痛苦你也无法停下脚步。你愿意吗？ | `如果成长的代价是失去，那我无所谓` / `我放弃了` |

失败状态名与结局标题对接：

- 系统内部的 `生活费断裂` 状态读取人生结局 `你破产了——有感觉吗！？`。
- 系统内部的 `没毕业` 状态读取人生结局 `毕业失败——你被延毕了！`。
- 中途失败结局可以包含后日谈；`被迫停学——好好休息，同学` 保留“后来毕业”的尾声，但规则上仍视为本局中途失败并结束。

同一路线内多个结局同时满足时，读取分数最高的结局；若分数相同，读取表格顺序更靠前的结局。所有结局都作为独立图鉴项收集。

素材与表现映射：

- 人生结局和成长成就的标题、内容、触发条件与分数以本文件总库为准。
- 结局图片映射维护在 `../asset-work/images/README.md`，运行时必须用人生结局标题或稳定结局配置 ID 读取图片，不用图片文件名反推规则。
- 结束曲抽取、失败结局绑定曲、底部歌词字幕和专辑旋转规则维护在 `../asset-work/music/README.md`。只有音乐清单中显式列入“失败结局绑定曲”的人生结局强制播放绑定曲；`保研失败——名单上没有你的名字。`、`再考一年——怕啥？你还没失败！`、`继续备考——别放弃，明年再战！`、转行失败等路线回落结局仍走普通结束曲抽取池。
- 人生结局图标和成长成就图标的生成前映射维护在 `../asset-work/prompts/ui-icon-page-inventory.md`，顺序跟随本文件表格；新增条目必须同步补图标映射。
