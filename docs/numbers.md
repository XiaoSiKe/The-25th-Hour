# 数值规则

## 值域

- 精力：基础上限 `100`；获得 `健身房年卡` 的学年内，临时上限为 `105`
- 压力：`0-100`
- 进度：普通学期 `0-100`，大五毕业设计累计 `0-250`；`原地开摆` 生效期间，当前评图周期进度值域上限直接减少 `10`，即普通学期 `0-90`、大五毕业设计累计 `0-240`
- 作品质量：普通学期 `0-100`，大五毕业设计累计 `0-250`
- 作品集总分：不设固定上限，首版按约 `0-900` 的体感区间校准
- 六项角色属性：`0-100`
- 个人 GPA 显示值和路线读取值：`0.0-4.0`
- 金钱：人民币元

补充规则：

- 任意结算后若金钱小于 `0`，立即触发中途失败结局 `生活费断裂`；金钱等于 `0` 不触发失败。
- 所有角色初始精力固定为 `100`；角色开局差异主要来自初始压力、初始金钱、六项角色属性、被动特质和专属技能。
- 临时精力上限只改变精力截断上限，不改变行动次数、周恢复规则或 `被迫停学` 判定。

## 结算与实现口径

- 所有数值变化必须写成结构化 delta，并交由统一结算器处理。
- 结算器统一负责上下限、六项属性轻衰减、失败检查、隐藏结果缓存和结算日志。
- 行动、事件、商店、实习、评图、考试、路线和结局不得各自绕过结算器直接改状态。
- 每局生成固定随机种子；事件抽取、考试抽题、实习录取、留学申请和岗位投递内部判定都必须可复现。
- 程序主键使用稳定 ID，展示标题和文案不作为规则读取依据。
- 规则触发必须读取明确状态字段、阈值、次数、周次、阶段、布尔标记或表格概率；不能只读取“较高 / 较低 / 明显 / 一般 / 倾向”等描述性文字。

固定枚举口径：

- 角色、学历背景、家庭背景、事件、行动、路线、商店商品、模型材料、竞赛和结局都必须使用稳定内部 ID。
- 正式游戏界面、角色卡、存档展示、结局文本和排行榜展示中的角色名、学历背景、家庭背景必须显示中文。
- 中文展示名不作为规则判断键；内部 ID 不直接暴露给玩家。
- 学历背景首版中文展示固定为：`双非`、`普通一本`、`双一流`、`建筑老八校`、`大专`。
- 家庭背景首版中文展示固定为：`贫寒`、`普通家庭`、`院士子女`、`富二代`。
- 中文名、描述文案和 UI 展示名调整时，必须通过内部 ID 映射迁移，不能破坏存档和统计。

角色卡等级只影响开局角色抽取展示和稀有度文案，不直接改变属性、压力、金钱、学历背景或家庭背景。抽取时按权重加权随机，权重越低越稀有。

成长节奏目标：

- 大一：多数属性仍在 `20-45`，只让玩家感到方向差异，不让强项成型过快。
- 大二：专注培养的属性进入 `45-65`，开始满足普通实习与部分低门槛路线前置。
- 大三：核心属性进入 `60-85`，角色养成方向感开始明显。
- 大四下：长期专注的 `1-3` 项属性可以接近或达到 `100`。
- 大五：不再主要承担基础属性养成，而是读取前四年形成的属性、作品集、实习和路线结果。

行动门槛补充：

- `接设计外包` 不再使用单一结算值，玩家选择行动后必须在外包项目中选择 `1` 项；不同项目读取不同能力门槛与收益代价。
- `接设计外包` 总入口每周最多选择 `2` 次；只要至少 `1` 个外包项目满足门槛，并且当前没有被精力/压力高危禁用，就可以在次数上限内重复选择，并按所选项目消耗周行动次数。
- `校外兼职` 无能力门槛；只要当前没有被精力/压力高危禁用，即可选择并进入兼职项目表。
- `校外兼职` 总入口每周最多选择 `2` 次。
- `接设计外包 / 校外兼职` 都按每个项目独立结算收益和代价；达到每周 `2` 次后，当周入口置灰并显示次数限制原因。
- `接设计外包 / 校外兼职` 的正向金钱收益不受状态风险削弱；轻度风险下正向 `进度 / 作品质量 / 六项属性` 各自 `-1`，高危下正向 `进度 / 作品质量 / 六项属性` 各自 `-2`。消耗、压力增加和门槛判断不因此变化。
- `场地调研` 不设每周次数上限；它仍正常消耗行动次数、金钱和精力，并受精力/压力高危限制；余额不足时只显示风险提醒。

## 行动联动修正

### 画图与赶图

- `正常速度画图` 与 `爆肝通宵赶图` 只直接负责 `进度` 推进，不直接增加 `作品质量`。
- 所有带 `基础进度` 的常驻行动都读取 `软件技术` 档位修正；事件进度加减不读取该修正。
- 大五阶段，`正常速度画图` 与 `爆肝通宵赶图` 的最终进度收益在原基础上额外 `+4`，仍受状态风险收益削弱影响。
- 普通学期进度硬门槛为 `90`；正常速度画图的调参目标是约 `7` 次行动补满进度。
- 爆肝通宵赶图是高代价捷径，调参目标是约 `5` 次行动补满进度。
- 随机事件、交互事件、导师任务和专属技能可以增减进度，因此实际所需画图次数允许上下浮动 `1-2` 次。
- 若玩家连续遇到负向进度事件，系统不额外放宽进度硬门槛，玩家需要通过画图、爆肝或技能补救。

| 软件技术 | 常驻进度行动修正 |
|---|---|
| `0-39` | 无修正 |
| `40-59` | 进度 `+1` |
| `60-79` | 进度 `+2` |
| `80-100` | 进度 `+3` |

- 无论 `软件技术` 多高，`爆肝通宵赶图` 的单次压力增量最低仍为 `+8`，单次精力消耗最低仍为 `-14`。
- 软件技术不再给低档惩罚，只提供小幅正向加成，避免大一阶段因为初始属性低而被进度硬门槛双重惩罚。

### 质量类行动

- 直接增加 `作品质量` 的常驻行动只读取 `方案推敲` 与 `场地调研`。
- `阅读/展览/讲座` 主要负责累计 `创意审美`，不直接增加 `作品质量`。
- `方案推敲` 与 `场地调研` 主要增加 `作品质量`，并固定附带 `进度 +1`，代表方案深化时顺手补完图纸逻辑。
- 所有带 `基础作品质量` 的常驻行动都读取 `设计水平 + 创意审美` 档位修正；事件、模型周材料和专属技能按各自表格结算，不额外读取该修正。
- 大五阶段，`方案推敲` 与 `场地调研` 的最终作品质量收益在原基础上额外 `+4`，仍受状态风险收益削弱影响。
- 质量修正采用简单相加口径：先计算 `质量理解 = floor((设计水平 + 创意审美) / 2)`，再按下表修正行动的 `基础作品质量`：

| 质量理解 | 质量行动修正 |
|---|---|
| `< 40` | `0` |
| `40-59` | `+1` |
| `60-79` | `+2` |
| `80-100` | `+3` |

- 质量类行动不再设置低属性惩罚；低属性只是不加成，避免大一阶段质量成长压力过高。
- 普通学期按 `18-20` 次可用行动校准：调参目标是 `4-5` 次质量投入可稳定摸到 `D` 门槛，`6-7` 次质量投入可进入 `C / B` 区间。
- 进度与质量合计不应吃掉整个学期；普通过关路线的调参目标是留下 `7-10` 次行动给学习、运动、放松、社交、兼职、万里路或突发补救。

## 状态收益修正

重复选择同一行动不做固定衰减，收益由精力和压力决定。

| 状态 | 条件 | 影响 |
|---|---|---|
| 正常 | 精力 >= `60` 且压力 <= `50` | 正常收益 |
| 轻度风险 | 精力 >= `30` 且 < `60`，或压力 > `50` 且 <= `80` | 行动产生的正向 `进度 / 作品质量 / 六项属性` 各自 `-1`；不做四舍五入，不把 `0.5` 抬高为 `1`；UI 启用浅红色低频呼吸 |
| 高危 | 精力 < `30` 或压力 > `80` | 行动产生的正向 `进度 / 作品质量 / 六项属性` 各自 `-2`；不做四舍五入，不把 `0.5` 抬高为 `1`；事件风险提高；UI 启用强红色呼吸并触发对应行动限制 |

提醒只保留两类：

- 状态高危
- 金钱高危

高危行动限制：

| 高危类型 | 条件 | 限制 |
|---|---|---|
| 精力高危 | 精力 < `30` | 禁用高消耗行动或持续消耗入口：`爆肝通宵赶图 / 接设计外包 / 校外兼职 / 万里路 / 实习申请`；交互事件中高消耗选项不额外警告，若结算后精力小于 `0` 则直接触发 `被迫停学` |
| 压力高危 | 压力 > `80` | 禁用 `方案推敲 / 场地调研 / 正常速度画图 / 爆肝通宵赶图 / 接设计外包 / 校外兼职`；专属技能不因压力高危额外禁用；交互事件选项不禁用，但会增加压力的选项显示红字风险提醒并自动淡出；负向事件基础权重绝对值 `+20` |
| 双高危 | 精力 < `30` 且压力 > `80` | 分别叠加精力高危与压力高危限制；未被任一规则命中的行动仍可执行，且至少保留 `休养生息`；商店商品不读取高危状态，仍按阶段、限购和余额独立判断，余额不足时置灰 |

高危提示文案口径：

- 状态高危：`你正在崩溃边缘，别画图了，快去休息！`
- 金钱高危：`你快要饿死了，省着点花！`
- 金钱高危触发条件：当前金钱低于该角色家庭背景对应的 `1` 周自动花费。
- 金钱高危不影响一般带花费行为的可执行状态；商店商品只按阶段、限购和当前余额判断，余额不足时置灰并显示原因。

### 状态 UI 呼吸

状态 UI 只做轻量视觉提示，不新增可交互系统。

| 状态 | 条件 | UI 呼吸规则 |
|---|---|---|
| 正常 | 精力 >= `60` 且压力 <= `50` | 不启用呼吸，仅显示普通状态条 |
| 轻度风险 | 精力 >= `30` 且 < `60`，或压力 > `50` 且 <= `80` | 状态区启用浅红色低频呼吸，提示玩家需要调整节奏 |
| 高危 | 精力 < `30` 或压力 > `80` | 状态区启用强红色中高频呼吸，对应高消耗或高压行动置灰 |

- 呼吸效果只改变颜色、透明度和轻微亮度，不改变布局尺寸，不遮挡按钮文字。
- 呼吸状态以最严重的一档为准。
- 当精力和压力同时触发不同档位时，按更严重档位显示；同档位同时触发时，仍只显示一次红色呼吸，不叠加动画。
- 浅红色呼吸触发条件为：`精力 >= 30 且 < 60`，或 `压力 > 50 且 <= 80`。
- 强红色呼吸与对应行动限制触发条件为：`精力 < 30` 或 `压力 > 80`。
- 高压和低精力统一使用红色呼吸，不使用蓝色或双色风险提示。
- 进入评图、结局和固定剧情文本时，呼吸效果降弱，避免干扰阅读。

## 每周自动恢复

- 每周所有行动、随机事件、交互事件、商店购买、实习收益/代价、自动生活费结算完成后，统一执行基础周恢复：`精力 +10`、`压力 -5`
- 任意结算后压力达到 `100`，立即触发中途失败结局 `压力失控——好好休息，同学`。
- 压力失控的连续周计数读取周结算后、基础周恢复前的压力状态；若压力 > `90` 连续 `2` 周，也触发 `压力失控——好好休息，同学`。
- 周恢复不占行动次数，不因 `模型周 / 赶图周 / 考试周` 改变
- 周恢复后再判断是否仍处于高危状态；若仍处于高危，只保留高危限制，不追加额外保底恢复

## 属性作用与成长

六项角色属性不再提供全局百分比加成，避免和行动档位修正重复叠加。每个属性只影响明确系统、行动档位或路线门槛：

- `软件技术`：影响 `正常速度画图 / 爆肝通宵赶图` 的进度档位修正，并参与技术型路线、实习和竞赛公式。
- `设计水平 + 创意审美`：共同影响 `方案推敲 / 场地调研` 的质量档位修正，并参与作品集、竞赛和多数建筑路线门槛。
- `汇报表达`：影响汇报策略可选门槛、体制内/升学/竞赛等表达型门槛。
- `人际交往`：影响社交、实习、体制内路线和部分事件选项。
- `抗压能力`：影响高压路线门槛、体制内路线和少数抗压相关事件。

属性成长规则：

- 不设置同一学期属性成长硬上限；玩家选择的行动、事件、商店、课程和实习只要完成，就正常结算，不因为本学期已成长过多而吞掉收益。
- 六项角色属性仍统一截断在 `0-100`；达到 `100` 后可以继续执行相关行动，但属性不再超过上限。
- 所有来源的六项属性变化都统一进入轻衰减，包括行动、事件、商店、课程、实习、导师阶段任务、万里路和角色技能。
- 当某项属性当前值低于 `80` 时，正向属性成长按表格原值结算。
- 当某项属性当前值达到 `80` 及以上时，正向属性成长进入轻衰减：最终成长 = `原成长 / 2`，不做四舍五入；例如原成长 `+1` 时最终为 `+0.5`。
- 当某项属性当前值高于 `20` 时，负向属性下降按表格原值结算。
- 当某项属性当前值为 `20` 及以下时，负向属性下降进入轻衰减：最终下降 = `原下降 / 2`，不做四舍五入；例如原下降 `-1` 时最终为 `-0.5`。
- `进度 / 作品质量 / 作品分 / 作品集总分 / 精力 / 压力 / 金钱 / GPA` 不使用六项属性轻衰减，按各自系统规则结算。
- 属性成长控制优先通过低初始值、较小单次增量、状态代价、金钱代价、路线复合门槛和轻衰减完成，不用学期硬上限控制。

## 事件数值结算

事件文本保留在 `events.md`，数值结算统一收口在这里。

收束原则：

- 每条事件单独对应一条数值结算
- 单个事件默认只改 `1-4` 个字段
- 事件默认不直接修改 `GPA / 作品集 / 简历价值 / 竞赛结果`
- 事件导致金钱小于 `0` 时，仍按总规则立即触发 `生活费断裂`
- 所有数值结算后统一做边界截断：`压力 / 六项角色属性` 保持在 `0-100`；普通学期的 `进度 / 作品质量 / 作品分` 保持在 `0-100`，大五毕业设计累计 `进度 / 作品质量` 保持在 `0-250`；`原地开摆` 生效期间，进度上限按当前评图周期减少 `10` 后再截断；作品集总分不设固定上限；精力允许先结算到负数并立即触发 `被迫停学`

触发体感口径：

- 大一至大三共 `36` 周，普通随机事件与交互事件按高频触发校准，体感目标约 `36` 次；允许少数周不触发，但不连续触发两次随机事件。
- 大一、大二提高 `台球少年`、`羽毛球`、`王者荣耀`、`剧本杀`、`电影`、`跑步`、`骑行` 等玩耍类交互事件权重；单局必须触发 `2` 次玩耍娱乐类交互弹窗，玩家是否选择娱乐选项不强制。
- 大一下至大二下提高 `搭讪`、`暧昧`、`偶遇`、`借笔`、`一起看展板`、`深夜同路` 等暧昧类交互事件权重；暧昧类事件与歌曲无关，符合 `hasPartner = false` 和阶段条件后，在大一下保底触发 `1` 次且大一下最多触发 `1` 次。
- `学妹请教`、`被学妹问软件` 等学妹请教类事件只在大三进入事件池。
- 大四共 `12` 周，焦虑类事件权重提高，体感目标约 `6` 次；自动随机事件中焦虑类事件目标占比为 `80%`。
- 大五共 `12` 周，回忆、成长和感动类事件权重提高，体感目标约 `6` 次；自动随机事件中感动、回忆和成长类事件目标占比为 `80%`。
- 固定事件、暑假写生和 `建筑生的万里路` 不计入上述 `50-60` 次随机体感目标；实习期间短事件实际发生时计入该目标，并占用普通正式周唯一自动事件名额。
- 模型周共 `9` 次，大五上第 `5` 周不进入模型周流程；其中 `6` 次触发模型周随机事件：大一 `2` 次、大二 `2` 次、大三下 `1` 次、大四下 `1` 次。大五上原模型周位置改为大五感动事件权重周。

### 事件权重与次数目标

单局正式周随机事件体感目标为 `50-60` 次。该目标统计实际触发次数，不等于事件库规模；普通随机事件库需要保留显著大于单局触发量的储备内容，用于冷却、阶段筛选、权重抽取和避免重复。固定流程事件、暑假写生节点与玩家主动触发的万里路事件不计入该体感目标；实习期间短事件实际发生时计入该体感目标，并占用普通正式周唯一自动事件名额，但不进入随机分池。

| 学年 | 目标次数 | 权重口径 |
|---|---:|---|

| 大五 | `6` 左右 | 回忆、成长、告别和感动类事件权重更高。 |

### 程序落地格式

程序层与规则层统一使用同一套事件字段口径：

```text
id
title
pool
sentiment
tags
contextTags
baseWeight
cooldownWeeks
repeatable
semesterMin / semesterMax
aiExperienceDelta
triggerRules
result
options
note
```

字段说明：

- `pool` 只允许：`normal / interactive / model / travel`，其中 `travel` 仅用于万里路主动地点事件，不参与自动随机抽取。
- 阶段限制优先写 `semesterMin / semesterMax`，特殊覆盖维护在代码的 `EVENT_PHASE_OVERRIDES`。
- `tags` 只服务筛选、冷却和权重，不新增玩法
- 普通事件若无特殊分类也必须写 `tags: []`；AI 相关事件必须写 `tags: ["ai"]`，不单独开事件池
- `contextTags` 只描述导师、课程、AI、地点等补充语境，按需填写，不参与当前核心抽取
- `repeatable` 标记事件是否允许作为重复候选；跨局历史候选耗尽后的兜底重复会回到当前阶段所有 `repeatable !== false` 的候选。同一局内已触发事件仍由事件历史排除；`cooldownWeeks` 保留为同标题或同事件间隔保护
- `triggerRules` 只描述保底、周次、阶段、黑名单、主动入口等触发覆盖条件；当前代码中的固定覆盖可维护在 `EVENT_PHASE_OVERRIDES` 等规则表
- 普通事件、模型周事件、万里路事件写 `result`
- 交互事件写 `options`
- `result` 与 `options` 必须直接写成结构化键值
- `title` 不作为程序主键，程序主键必须使用 `id`

首版最小必填字段：

```text
id
title
pool
result / options
```

补充规则：

- 首版可以先只消费最小必填字段完成抽取与结算
- `tags / contextTags / baseWeight / cooldownWeeks / repeatable / aiExperienceDelta / triggerRules` 仍视为正式字段，不再另起第二套简化格式。
- `aiExperienceDelta` 只允许写在 AI 交互事件的偏 AI 选项上；普通 AI 随机事件和常驻行动不得直接增加 `AI 相关经历`。
- 首版额外权重读取 `baseWeight / cooldownWeeks / repeatable / semesterMin / semesterMax / tags`；大四焦虑类和大五感动、回忆、成长类事件按 `80%` 目标占比做阶段加权，其余语义重复、同类过密与 `分享会` 大四加权不另设公式。

## 评图

评图采用三段制：先结算并揭示导师阶段任务完成情况，再判定进度硬门槛与基础图纸评级，最后结算汇报策略对最终等级、作品分和设计课绩点的影响。汇报策略完成后先显示“汇报成功 / 汇报失败”，再进入最终评图等级展示。

进度硬门槛：

| 阶段 | 进度要求 | 未达成结果 |
|---|---:|---|
| 大一至大四普通课题 | 评图前进度必须达到 `90 / 100` | 本次评图直接为 `F`，不可用汇报策略补救 |
| 大五上毕业设计积累期 | 不评图；大五上结束后进度和作品质量不清零 | 继续进入大五下，不在大五上形成设计课评级 |
| 大五下毕业设计答辩 | 答辩前毕业设计累计进度必须达到 `240 / 250` | 未完成毕业设计，读取 `毕业失败——你被延毕了！` |

若角色专属技能 `我开摆了` 已在当前评图周期发动，进度值域上限减少 `10`。普通学期进度硬门槛减少 `10`，从 `90 / 100` 变为 `80 / 90`；大五毕业设计进度硬门槛减少 `10`，从 `240 / 250` 变为 `230 / 240`，且最终评图等级最高锁定为 `B`。

质量评图分：

- 大一至大四直接读取当学期作品质量，范围 `0-100`。
- 大五毕业设计作品质量范围为累计 `0-250`；最终答辩评图时折算为 `质量评图分 = floor(作品质量 / 250 * 100)`。
- 按大五 `0-250` 原始作品质量折算，等价门槛为：`S = 250`，`A = 225-249`，`B = 200-224`，`C = 175-199`，`D = 150-174`，`F = 0-149`。
- 模拟器中的评图支持只按质量评图分进入 `50-79` 支持窗口，最多补 `20` 分且目标不超过 `80`；大五毕业设计先折算为 `0-100` 质量评图分，再换算回 `0-250` 作品质量增量。
- 若质量评图分低于 `60`，基础图纸评级为 `F`。
- `求求你别挂我` 只在进度硬门槛已达成、基础图纸评级因质量不足为 `F`，且此时满足 `质量评图分 < 60 且精力 < 60` 或 `质量评图分 < 60 且压力 > 50` 时可选；进度不足导致的 `F` 不进入可补救分支。
- 基础图纸评级先由质量评图分决定；随后汇报策略可以在固定成功率下改变最终图纸评级、作品分和设计课绩点。

导师阶段任务、模型材料和事件只允许在评图前改变 `作品质量 / 进度 / 状态 / GPA 学期修正`。若角色技能明确写作 `个人 GPA`，则属于立即生效的个人 GPA 直接修正，不等到本学期评图。汇报策略不再改变 `进度` 或 `作品质量`，只在基础图纸评级产生后影响 `最终图纸评级 / 作品分 / 设计课绩点`。

导师阶段任务数值口径：

- 每学期第 `1` 周发布当前导师的 `1` 个阶段任务。
- 阶段任务只统计当学期行动、实习、竞赛投稿、当学期课题状态和本学期属性成长量；新学期开始时任务进度清零。
- 阶段任务统一在评图前结算，只有 `完成 / 未完成` 两档，不做半完成。
- 完成奖励和未完成处罚以 `content-plan.md` 的导师阶段任务表为准。
- 完成奖励允许提高 `作品质量 / 进度 / 六项角色属性 / GPA 学期修正 / 状态`，但不直接改变最终评图等级。
- 未完成处罚允许降低 `作品质量 / GPA 学期修正` 或提高压力；不直接触发失败结局。

作品分：

- `作品分` 是这份课题在评图和汇报后的最终量化分数，用于竞赛获奖概率、作品集增长、路线门槛和结局结算。
- 基础作品分默认等于 `质量评图分`。
- 汇报策略可以在基础作品分上加减固定分值，但最终仍截断在 `0-100`。
- 最终作品分必须落在最终图纸评级对应的分数区间内：`S=100`，`A=90-99`，`B=80-89`，`C=70-79`，`D=60-69`，`F=0-59`。
- 若汇报策略导致评级升档或降档，先调整最终图纸评级，再把作品分截断到新评级区间内；例如 `B` 升到 `A` 后，最终作品分最低为 `90`。
- 进度硬门槛未达成导致的 `F`：最终作品分固定为 `0`，不进入作品集。
- 质量不足导致的 `F`：未补救时最终作品分保持在 `0-59`；若任一汇报策略成功补救为 `D`，最终作品分至少为 `60`，最高仍不超过 `69`。

等级与绩点：

| 基础图纸评级 | 设计课绩点 | 质量评图分 |
|---|---:|---|
| S | `4.0` | `100` |
| A | `3.7` | `90-99` |
| B | `3.2` | `80-89` |
| C | `2.4` | `70-79` |
| D | `1.3` | `60-69` |
| F | `0.0` | `0-59` 或进度硬门槛未达成 |

规则：

- `D` 视为过关
- `F` 视为挂科
- `F` 的本学期评图绩点仍为 `0.0`，并记录为挂科。
- 个人 GPA 的最终显示值和路线读取值统一截断在 `0.0-4.0`；这不改变 `F` 的挂科性质。
- 每次评图结算完成后，按顺序显示：导师任务完成情况 UI、汇报策略结果 UI、最终图纸评级与作品分 UI。最终图纸评级不得在汇报结果 UI 之前揭晓。
- 累计 `2` 次 `F` 直接触发 `挂科两次被劝退`；若累计第 `2` 次 `F` 发生在大五下毕业设计答辩且毕业设计未完成，则读取 `毕业失败——你被延毕了！`

## GPA 结算

- 开局显示 `GPA = 未知`
- 每学期先根据最终评图等级得到 `评图绩点`
- 若最终评图等级不是 `F`，再叠加本学期 `GPA学期修正`，得到 `本学期计入绩点`
- 若最终评图等级是 `F`，本学期计入绩点固定为 `0.0`，不吃正向修正
- 非 `F` 学期的本学期计入绩点截断在 `0.0-4.0`
- 个人 GPA 显示值和路线读取值截断在 `0.0-4.0`
- GPA 已经是 `4.0` 时，任何正向修正后仍为 `4.0`。
- GPA 已经是 `0.0` 时，任何负向修正后仍为 `0.0`。
- `GPA学期修正` 与 `个人 GPA 直接修正` 是两类不同结算：前者只影响本学期最终计入绩点，后者立刻改变个人 GPA 显示值和路线读取值。
- GPA 修正使用固定加减值，不使用百分比。
- 评图等级是 GPA 的主要来源；`GPA学期修正` 只做小幅修正，不能把 `F` 补成合格绩点。
- 若本学期最终图纸评级为 `F`，正向和负向 `GPA学期修正` 都不再改变本学期计入绩点；该学期固定按 `0.0` 计入平均。
- `个人 GPA 直接修正` 不改变任何已完成学期的最终绩点，也不改变 `F` 的挂科记录；它只作为个人 GPA 总读数上的直接加减项保留。

累计规则：

```text
本学期计入绩点 = finalRating == F ? 0.0 : clamp(评图绩点 + GPA学期修正, 0.0, 4.0)
个人GPA = 已完成学期数 == 0 且 个人GPA直接修正 == 0 ? 未知 : clamp(所有已完成学期计入绩点的平均值 + 个人GPA直接修正, 0.0, 4.0)
```

示例区分：

- `S + GPA学期修正 +0.2`：`4.0`，因为已到上限。
- `A + GPA学期修正 +0.2`：`3.9`。
- `B + GPA学期修正 +0.05`：`3.25`。
- `C + GPA学期修正 -0.15`：`2.25`。
- `D + GPA学期修正 -0.35`：`0.95`。
- `F + GPA学期修正 +0.2 / -0.35`：本学期计入绩点都是 `0.0`，仍记录为挂科。
- `个人 GPA 直接修正 +0.10`：个人 GPA 显示值和路线读取值立即 `+0.10`，之后评图重算时仍保留这项直接修正。
- 若还没有完成任何学期评图，且没有任何 `个人 GPA 直接修正`，个人 GPA 显示为 `未知`，后期路线不读取 GPA。

## 作品集

作品集采用总分制，不再是 `0-100` 的单项属性。

规则：

- `作品集总分 = 所有已完成且最终图纸评级为 C 及以上课题的作品分之和`。
- `D / F` 评级作品不进入作品集，作品集增量为 `0`；`D` 仍视为课程通过，但不算作品集成果。
- 作品集总分不设固定上限，不做轻衰减；首版按约 `0-900` 的体感区间校准。
- 作品集只保留一个总分，不拆子分。
- 竞赛不直接增加作品集总分；竞赛只记录投稿、奖项、奖金和简历标签。
- 万里路不进入作品集总分，只进入简历与成长路径。
- 实习、商店、课程、随机事件和导师阶段任务都不能直接增加作品集总分；它们只能通过影响作品质量、最终作品分或简历标签间接发挥作用。
- 大一至大四每次正式评图结算后，若最终评级为 `C / B / A / S`，本次作品分立即入库。
- 大五毕业设计只在大五下最终答辩后按 `C / B / A / S` 门槛入库 `1` 次；大五上不评图、不入库，进度和作品质量继续累积到大五下。

## 建筑生的万里路

触发规则：

- 万里路按固定地点顺序推进；玩家选择前往当前地点后，先弹出对应万里路事件，事件弹窗的结算按钮确认后才结算数值。
- 前 `6` 个地点每次消耗 `1` 次行动机会，后 `6` 个地点每次消耗 `2` 次行动机会；当前周剩余行动次数不足本次行动消耗时仍可前往，超出的行动次数从下一周行动次数中扣减。
- 前 `6` 个地点每次额外消耗金钱 `2500`，后 `6` 个地点每次额外消耗金钱 `4000`；余额不足时前往按钮置灰，并在消耗信息旁显示红色 `余额不足` 状态。
- 大二上开始开放，开放后不再按学年关闭；一学年最多前往 `6` 次。入口未满足开放年级、已借用下周行动次数、达到学年次数上限或余额不足时仍展示，并提示触发条件。

- 万里路事件不计入普通正式周唯一自动事件名额。
- 玩家第一次在模型周或赶图周使用万里路时，触发成长成就 `忙里偷闲`。

## 升学路线组

升学路线必须在大五阶段正式参与 `保研 / 考研 / 留学` 之一。保研和考研不能同时进行；大一至大四的后期路线入口只展示候选条件，不记录任何后期路线状态。

大五阶段所有路线正式参与前，均先弹出对应路线确认弹窗；`创业` 只弹出 `恶魔的契约`，签下后不再弹出路线确认或等待结果提示。取消确认不形成路线正式参与记录，不消耗报名、考试、申请或投递机会，也不写入路线失败。

### 升学专业考试

保研复试与考研初试共用 `升学专业题库`。

- 题库总量：以 `question-banks.md` 当前题目数为准
- 每次抽取：`10` 道
- 难度组成：`6` 道简单题 + `4` 道困难题
- 内部先记录答对题数，再折算为现实分数线
- 答题过程中不反馈单题对错，也不显示正确答案
- 每道升学专业题出现后，题页右上角显示 `60` 秒倒计时；倒计时结束仍未作答时，该题判错并自动进入下一题或考试结算；时钟图标使用 `003_游戏主要过程界面时钟图2__时钟图2.414900d928ef.webp`
- 大五阶段正式参与 `保研` 或 `考研` 后，若满足考试触发条件，则立即进入本路线考试阶段；大五上正式参与不再等到大五下
- 考试结束后只记录内部得分与是否过线，不向玩家公开分数、答对题数或上岸结果
- 考试结束后弹出统一等待结果提示；文案读取 `content-plan.md` 的“路线等待结果弹窗文案”。
- 保研、考研是否成功统一延后到大五下毕业设计答辩后的结局结算再揭示
- 折算规则：答对 `10 / 9 / 8 / 7 / 6` 题时，分别折算为 `410 / 395 / 380 / 365 / 350` 分；答对 `5` 题及以下统一视为 `350` 分以下

- `创业` 入口只在六项属性全部 `>= 80` 时可选择；满足后弹出 `恶魔的契约`。选择 `如果成长的代价是失去，那我无所谓` 立即形成路线正式参与记录并锁定读取 `没有退路的选择——一条最孤独之路`，不再弹出路线确认或等待结果提示；选择 `我放弃了` 等同于取消本次选择，不锁定路线，不读取转行失败。

结果揭示规则：

- `转行` 路线在大五阶段只完成岗位投递和内部判定
- 转行简历只能投 `1` 个具体岗位；非创业岗位首次投递前弹出确认提示，文案读取 `content-plan.md` 的“路线投递确认弹窗文案”。
- `创业` 不属于简历投递，不弹出投递确认提示或路线等待结果提示，但必须弹出 `恶魔的契约` 二选一确认。
- 非创业岗位投递确认弹窗中选择取消时，不形成路线正式参与记录，不消耗投递机会，也不写入转行失败。
- 非创业岗位投递前必须满足已确认岗位门槛；未满足时入口置灰，只展示缺失条件。
- 非创业岗位投递完成时锁定内部判定结果；后续属性、作品集或 AI 相关经历变化不重算转行结果。
- 非创业转行岗位投递结果概率：满足已确认岗位门槛但未达到“大幅超过”条件时成功率为 `80%`；至少 `2` 个核心指标达到“大幅超过”时成功率为 `100%`。大幅超过口径：作品集总分高出 `60`、AI 相关经历高出 `1`、任一岗位属性高出 `8`。
- 非创业转行成功结局必须同时满足：已正式参与 `转行`、已确认对应岗位、完成毕业设计、当次投递内部判定成功。
- `转行失败——转行可不是那么容易的！` 读取条件为：已正式参与非创业 `转行`、已确认对应岗位、完成毕业设计、当次投递内部判定失败。
- 转行岗位投递完成后只缓存内部结果，不提前公开成功或失败，并弹出统一“路线等待结果”提示。
- 是否转行成功统一延后到大五下毕业设计答辩后的结局结算再揭示

## 毕业设计完成门槛

顺利毕业必须完成毕业设计；否则无论路线是否达标，都读取 `毕业失败——你被延毕了！`。该分支在评图结果页确认后直接进入结局页面，不触发毕业典礼或结尾回忆。

大五上和大五下共同承载同一个毕业设计题目，使用同一组累计进度与作品质量。两项上限均为 `250`；大五上结束后不评图、不清零，当前进度与作品质量直接带入大五下。

大五上过程口径：

- 大五上不设置正式评图和模型周，不生成期中设计课评级、GPA 或作品集入库。
- 大五上第 `5` 周原模型周位置改为大五感动事件权重周；毕业设计进度与作品质量继续通过行动、事件、导师任务和技能累积。

毕业设计完成条件：

- 大五下毕业设计最终评图等级为 `D` 或以上
- 大五下评图前毕业设计累计进度必须达到 `240 / 250`；若 `我开摆了` 已发动，本次门槛为 `230 / 240`
- 大五下毕业设计作品质量折算后的质量评图分若低于 `D`，只有在汇报策略成功补救为最终评级 `D` 时，才视为满足毕业设计质量完成口径；可补救来源包括 `求求你别挂我` 成功，或满足属性门槛的 `我就是大师 / 高级技术流` 成功升档
- 大五下毕业设计答辩一结束，立即进入结局系统结算；此前所有路线考试、申请、投递的内部结果都在此时统一读取

状态收尾：

| 状态收尾 | 条件 |
|---|---|
| 普通 | 通关时不满足沉重 |
| 沉重 | 通关时精力 < `35` 或压力 > `75` |

## 强路线稀有度

强路线不是失败条件，只影响成功通关时的主结局优先级。

| 强度 | 路线 | 目标体感 |
|---|---|---|
| 顶级强路线 | 强校保研上岸、强校考研上岸、顶级名校留学、选调回乡、大师建筑事务所 | 需要明确规划；大师建筑事务所应极稀有但真实可达 |
| 中强路线 | 考研上岸、普通留学、国企设计院、AI 新职业 | 合理规划可达成 |
| 普通路线 | 地方设计院、独立小型工作室、基层公务员、非 AI 转行、状态毕业 | 大多数未失败玩家可回落 |

调参原则：

- 若强路线过多触发，优先上调 `作品集 / GPA / 实习价值 / AI 相关经历` 门槛
- 若普通通关过难，优先降低失败压力，不降低强路线门槛
- `稳定毕业——平平淡淡才是真！ / 带伤毕业——你看起来有点糟！` 不读取作品集、竞赛、实习等强路线条件

## 中途失败阈值

- 生活费断裂：任意结算后金钱小于 `0`，读取人生结局 `你破产了——有感觉吗！？`
- 压力失控：压力 `> 90` 连续 `2` 周，按周结算后、基础周恢复前状态计数，读取人生结局 `压力失控——好好休息，同学`
- 挂科两次劝退：累计 `2` 次评图 `F`，读取人生结局 `挂科两次被劝退——也许你并不适合`；大五下毕业设计未完成同时形成累计第 `2` 次 `F` 时，读取 `毕业失败——你被延毕了！`
- 被迫停学：任意结算后精力小于 `0`，立即读取人生结局 `被迫停学——好好休息，同学`
