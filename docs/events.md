# 事件体系

## 当前口径

- 本文档维护自动随机事件体系中的普通随机事件、交互事件、模型周事件，以及固定流程事件、暑假写生固定交互事件、实习期间短事件和万里路地点事件的标题、内容和交互选项。
- 事件属性结算、权重公式、阶段奖励和数值平衡统一放在 `numbers.md`。
- 系统规则、触发流程和开放节点统一放在 `systems.md`。
- 事件结构化字段是开发配置，不在本文档逐条维护；本文档保持为事件文案与选项清单。
- 标题和内容以已经拍板的版本为准；已确认文本不再为了凑数量、压缩字数或统一风格而改写。

## 单局体感

- 单局事件触发次数、学年权重、分池比例和保底规则统一维护在 `numbers.md` 与 `systems.md`。
- 本文只保留事件体感方向和内容池边界。
- 固定流程事件和暑假写生节点不计入单局随机事件目标；实习期间短事件实际发生时计入单局 `50-60` 次体感目标，且占用普通正式周唯一自动事件名额，但不进入随机分池。
- 大一、大二为高触发期，普通随机事件与交互事件的平均触发概率高于后续学年。
- 节奏目标为：普通随机事件和交互事件在体感上经常前后呼应；连续 `2` 次普通随机事件的目标概率见 `numbers.md`。
- 事件库数量可以超过早期目标数；超过后不删确认内容，只调整事件池规模口径。

## 固定必触发与保底事件

| 类型 | 事件 | 次数口径 |
|---|---|---|
| 固定流程 | 开学典礼 / 军训 / 建院生活开始提示 / 学年开始提示 / 毕业典礼 | 每局按流程固定触发，不计入随机事件目标。 |
| 阶段必触发 | 轻松绷住 | 每位玩家大一下固定触发 `1` 次，计入普通随机事件目标。 |

| 阶段保底 | AI 相关事件 | 单局保底 `2` 次、目标 `3` 次、软上限 `3` 次，计入对应普通随机事件或交互事件目标。 |
| 主动固定顺序 | 建筑生的万里路 `12` 个地点 | 玩家主动前往当前地点后必定触发，不进入 `RANDOM_EVENTS`，不计入随机事件目标。 |

## 当前事件池规模

- 普通随机事件：首版下限 `80`，当前游戏配置 `143` 条。
- 交互事件：首版下限 `40`，当前游戏配置 `49` 条；另有暑假写生固定交互事件 `1` 条，不进入随机池统计。
- 模型周事件：当前游戏配置 `12` 条。
- 万里路事件：固定 `12` 条，不进入 `RANDOM_EVENTS` 随机池统计。
- 当前 `RANDOM_EVENTS` 总量：`204`，其中 `143` 条普通随机事件、`49` 条交互事件、`12` 条模型周事件。
- 单局体感目标是正式周随机事件触发约 `50-60` 次；事件库规模是储备池，可以显著大于单局触发次数。

## 分池职责

- 普通随机事件：直接出现并结算，没有玩家选项。
- 交互事件：出现后给玩家 `2` 个选项。
- 模型周事件：只在模型周触发，当前配置为正向 `6` 条、负向 `6` 条。
- 万里路事件：跟随“建筑生的万里路”固定顺序触发，是主动地点事件，不进入自动随机事件分池。
- AI 相关事件不再单独开池，按是否有选择分别放入普通随机事件或交互事件。
- 大四焦虑事件只在大四进入池；首版按阶段与标签权重进入开发配置。
- 大五感动事件只在大五进入池；首版按阶段与标签权重进入开发配置。大五上第 `5` 周原模型周位置优先抽取大五感动事件，不触发模型周事件。

## 重复与冷却

- 同一局内已触发过的自动随机事件不会再次进入候选，避免玩家在单局内反复遇到同一事件。
- 跨局历史避重作用于普通随机事件和交互事件：只要当前候选中仍有未玩过的事件，就优先排除历史已玩过的事件；当前候选都已玩过时，不清空历史记录，但回到当前阶段所有 `repeatable !== false` 的候选作为兜底重复。模型周事件池较小，暂不进入跨局历史避重。
- 同标题事件默认 4 周内不重复；若同标题未来拆成多个 `id`，仍共享标题冷却。
- 兜底重复仍尊重同一局内事件历史、同标题冷却和 `repeatable` 标记；`repeatable: false` 的事件不进入跨局历史耗尽后的兜底候选。
- 自动随机事件体系内，所有带选项、带抽奖、带概率分支的事件，统一归入交互事件；暑假写生是固定交互表现，路线确认弹窗是系统流程，不并入交互随机池。
- 普通随机事件抽取时按“负向 / 正向与中性”做体验归一化，保证体感接近 `1:1`，不要求内容表格本身强行等量。
- 开发配置中每条事件必须补 `id / pool / sentiment / tags / baseWeight / cooldownWeeks / repeatable` 等结构化字段；阶段限制用 `semesterMin / semesterMax` 或 `EVENT_PHASE_OVERRIDES`，语境补充用可选 `contextTags`。
- AI 相关事件通过 `tags` 中的 `ai` 标记，不单独开事件池；只有 AI 交互事件中的偏 AI 选项可以写 `aiExperienceDelta`，常驻行动和普通随机事件不增加 `AI 相关经历`。
- `id` 是开发配置主键，发布后保持稳定；标题和文案可以调整，但不作为程序读取依据。

## 固定流程事件

固定流程事件不计入普通随机事件池。开学典礼和军训发生在游戏正式进入周行动前，此时所有行动不可使用；军训结束后进入建院生活提示页，随后选择大一导师，再开始大一上第 `1` 周。

### 开学典礼

开学的新生典礼，你坐在建院报告厅靠走廊的位置，看阳光从高窗斜进来，落在前排女生的马尾辫上。<br>
台上的人说着建筑、理想和远方，你一个字都没听进去，只是在想：我会在这里遇见谁？<br>
院长讲话的时候，你掏出手机拍了一张PPT，上面写着“欢迎新同学”。<br>
那张照片在你的相册里存了五年，每次清理手机都舍不得删。散场后你站在大学广场上，夕阳把整个校园染成橘色。<br>
你打开手机给妈妈发了一条消息：“典礼结束了，一切都好。”她回了一个“好”字。<br>
你盯着那个字看了一会儿，觉得这个字比任何建筑都稳。<br>
你收起手机，跟着人群往前走，不知道要去哪里，但你知道你会找到的。

| 太困了，先睡觉 | 你在掌声里睡了一小会儿，醒来时只记得阳光和那个“欢迎新同学”。 |

### 军训

九月的太阳还毒，你站在操场上，帽檐压得很低，汗水顺着脖子往下淌。<br>
教官喊“齐步走”，你同手同脚走了三步，被隔壁的同学小声提醒“换边”。<br>
你涨红了脸，偷偷看旁边那个女生，她比你还紧张，步子迈得像在跳格子。<br>
休息时你们坐在滚烫的塑胶跑道上，有人递过来一瓶水，你不认识他，他说“都是一个院的”。<br>
你拧开盖子，喝了一大口，觉得这大概是大学里第一口甜的。<br>
晚上拉歌，你们坐在草坪上，对着星空吼跑了调的《团结就是力量》。<br>
你笑到肚子疼，笑完以后抬头看天，忽然觉得，未来好像也没有那么可怕。

### 建院生活开始提示

军训结束了。你拖着还有点酸的腿走进建院，专教的灯亮着，楼道里有人抱着图板跑过去。<br>
你还不知道接下来五年会发生什么，但从这一刻起，你正式成为这里的一部分。

### 大二开始提示

标题：专教生活

感觉怎么样？此时的你应该已经在专教找到了那个“你的”角落。椅子上有你的屁股印，桌角贴着你写的“别动”，抽屉里塞着半包饼干和一卷用了一半的硫酸纸。大一你忙着适应，大二你开始学会生活。

### 大三开始提示

标题：大学倒计时

大学生活将近过半，此时的你开始深切感受到时间的重量。<br>
大一的事好像就在昨天，但一转眼你已经是学长学姐。不过你不再无忧无虑，你开始思考：画完图之后呢？<br>
你思虑万千，犹豫不决，你看起来好像总是不太开心。

### 大四开始提示

标题：人生的十字路口

大四了，你不再是大一那个连丁字尺都拿反的新生，你开始思考人生，就像思考一条总图上偏了两米的轴线——改还是不改？是保研、考研？出国留学？考公、考编、考选调？建筑就业还是转行？哪个都不好走，但哪个都比大一第一次交图的前夜轻松一点。反正你连通宵都扛过来了，还怕做选择吗？记住：选错了也可以改，建筑学不是教会了你“Ctrl+Z”吗？

### 大五开始提示

标题：画了五年，该交图了！

转眼就到大五了，你还记得第一次走进建院的那天吗？现在，菜单栏里的所有毕业通道都已开放——申请保研、考研升学、出国留学、考公考编选调、建筑就业和转行，每一条都通向一个不同的明天。看来黄色的树林里不止分出两条路，少年，你的选择是什么呢？五年的建筑学教了你怎么给别人盖房子，最后一年，你该给自己选一块地了。祝你好运，未来的建筑师。

说明：本提示允许提及毕业通道已经开放，但只作为学年氛围文案；不额外弹路线开放提示，不显示红点，不做催促 UI。

学士服穿在身上有点大，帽子怎么也戴不正。<br>
摄影师喊“三、二、一”，所有人同时把学士帽扔向天空。

帽子落下来的那一秒，你忽然看见了五年前的自己——<br>
站在校门口，拖着行李箱，仰头看建院的招牌。

那时候你觉得五年很长，长得像画不完的剖面。现在它短得像一声快门。<br>
你站在人群里，左右是熟悉的脸，有些人你甚至叫不全名字，<br>
但你知道，你们共享过同一间教室的灯、同一卷硫酸纸的痕迹、同一把美工刀划破手指的疼。

按钮：再来一张

### 毕业照二阶段

摄影师说“再来一张”，你把手搭在旁边同学肩上，他冲你比了个耶。<br>
你想起某个凌晨，你们一起在专教改图，他分了你半罐红牛，<br>
你说“谢了”，他说“别废话，快画”。

那些夜晚回不去了。

快门再次按下，这张照片里，你笑得比第一张自然。

你知道，再过很多年，你翻到这张毕业照时，<br>
会记得今天的风、阳光、还有身边这些人的声音。<br>
身边的同学在自拍、在拥抱、在大喊“毕业了”，你也跟着笑了。<br>
可你知道，你心里有一块地方，安静得像专教深夜的走廊。<br>
你问自己：这五年，我到底变成了谁？没有答案。<br>
但你知道，<br>
你不再是那个会在图纸前哭的小孩了。<br>
你对自己说：就这样吧，挺好的。<br>
然后你弯腰，<br>
捡起掉在地上的学士帽，拍了拍灰，走向下一个路口。

按钮：从前有个少年，他/她以为五年很长……

### 结尾回忆动画

结尾回忆使用图片序列动画。毕业照二阶段确认后进入动画播放。

按钮：同学，毕业快乐！

毕业典礼是完成毕业设计后的游戏尾声固定事件，不再结算属性；毕业典礼结束后进入两段毕业照节点和结尾回忆动画，动画完成或允许跳过后进入统一结局系统。毕业失败延毕不触发毕业典礼或结尾回忆。

结尾回忆动画只承担尾声表现，不参与属性、路线或结局规则结算；中途失败和毕业失败延毕不播放完整毕业回忆，直接进入对应失败结局。动画由 `hyperframes/ending-memory/` 嵌入播放，场景图片读取优化后的 WebP。

| 萨伏伊别墅 | 背了无数遍的“五点原则”，终于不再只是考试答案。你一边走一边想：原来现代主义最厉害的地方，是它真敢把生活方式也一起设计掉。 |
| 范斯沃斯住宅 | 玻璃多到你几乎没有地方躲。你第一反应不是高级，而是：住在这里，真的不会觉得自己像被陈列起来了吗？ |
| 包豪斯校舍 | 它不像一栋普通学校，更像一台高速运转的教学机器。你突然理解了，为什么有些建筑本身就是一种立场。 |
| 萨尔克生物研究所 | 中庭那条细细的水线，把海和天都收进了秩序里。你站在那里，第一次觉得“克制”居然也可以这么有力量。 |
| 金贝尔美术馆 | 光从顶部落下来，像被人认真修过边。你抬头看了很久，终于承认：天光这件事，真不是开个洞就完了。 |
| 苏州博物馆 | 白墙灰瓦在贝聿铭手里变得很轻，也很准。你边走边想，原来真正的“中式”不是堆元素，而是知道什么该留、什么该收。 |
| 香港中银大厦 | 它立在那里像一把出鞘的刀，锋利得几乎不解释自己。你仰到脖子发酸，只想回去把自己画得发软的立面全删了。 |
| 广州大剧院 | 扎哈把一块石头吹成了流动的地貌。你绕着它走了半天，最后承认一句：有些形体，屏幕上看和现场看根本不是一回事。 |
| 流水别墅 | 赖特让房子直接压在瀑布上，像在和自然赌气。你一边惊叹一边默默想：要是真住这里，晚上会不会吵得根本睡不着？ |
| 哈佛设计研究生院 | 一群大师盖的。你进去第一反应：这楼梯怎么这么窄？然后听说是故意设计的，为了让学生多撞见、多交流——好吧，有道理。也正因为这样，这地方确实让人总想再待一会儿，再讨论一点什么，再多想一步。 |
