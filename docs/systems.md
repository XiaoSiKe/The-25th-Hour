# 游戏系统架构

## 总体结构

游戏按 `周 -> 学期 -> 学年 -> 五年` 推进。

- 一学期：`6` 周
- 一学年：`12` 周
- 完整流程：`5` 年，共 `60` 周
- 每周固定：`3` 次行动
- 第 `5` 周：模型周；大五上第 `5` 周改为大五感动事件权重周，不进入模型周
- 第 `6` 周：赶图周
- 赶图周结束后：大一至大四和大五下进入评图阶段；大五上直接进入大五下，毕业设计进度和作品质量不清零

首版体验定位：

- 产品定位读取 `PRD.md`；本文只维护流程顺序、系统关系和规则职责。
- 每周核心压力来自固定 `3` 次行动机会的取舍，不来自复杂菜单、隐藏系统或多路线并行管理。
- 普通通关应稳定可达，强路线保持稀有，中途失败要有明确预警。

### 程序状态机

开发实现必须以显式阶段状态机推进，不允许由 UI 页面各自决定流程。

推荐阶段顺序：

1. 开局档案填写
2. 开局角色选择
3. 固定流程事件
4. 学期开始
5. 周开始
6. 周行动
7. 周结算
8. 评图阶段
9. 学期结算
10. 年度切换
11. 后期路线入口开放与正式参与
12. 毕业典礼
13. 结局结算

规则：

- 游戏状态必须写入统一 `GameState`，UI 只读状态并发起操作。
- 行动、事件、商店、实习、评图、路线和结局都只能通过统一结算器修改状态。
- 每次结算都必须产出结构化数值变化和结算日志。
- 每局生成固定随机种子；随机事件、考试抽题、实习录取、留学申请和岗位投递内部判定都必须可复现。
- 自动存档点固定为：每周开始、每周结束、评图前、评图后、路线正式参与后、结局结算前。

### 流程顺序收束

除各系统章节另有明确规则外，主流程按以下顺序归位：

1. 开局档案、角色选择和固定开场事件完成后，进入大一导师与课程选择。
2. 从大二开始，每个新学年先选择导师和课程，再显示学年开始提示。
3. 每个正式周开始时，先处理本周固定入账或强制选择；模型周材料选择在本周事件与行动前完成，大五上第 `5` 周跳过模型材料选择。
4. 周内由行动、商店、实习申请、路线入口和随机事件共同推进；随机事件是否在行动中间或周结算触发，读取事件系统的触发原则。
5. 周末统一收束当周结算；每个结算节点仍按统一失败规则即时检查，压力失控连续周计数在基础周恢复前更新，基础周恢复后再更新高危状态。
6. 赶图周结束后，大一至大四和大五下进入评图阶段；导师阶段任务先结算，随后判定评图与汇报策略，最后展示最终评级和作品分。大五上不评图，直接进入大五下。
7. 评图或大五上学期收束后进入学期结算；GPA、作品集、毕业设计阶段切换、可投稿作品和年度切换按各自系统职责处理。
8. 大五路线考试、申请、投递或确认只写入内部状态；除创业契约外，完成后统一进入等待结果提示，最终结果统一留到毕业设计答辩后的结局解析器读取。
9. 完成毕业设计后的毕业典礼和结尾回忆只承担尾声表现，不再修改属性、金钱、课题、路线或结局规则；毕业失败延毕分支从评图结果页直接进入结局页面。

### 系统职责分界

- 本文定义“什么时候发生、由哪个系统负责、是否形成状态记录”。
- `numbers.md` 定义“具体加减多少、门槛是多少、概率是多少、权重如何分配”。
- `endings.md` 定义“读取到哪个人生结局、成长成就和排行榜分数”，不反向改写流程与数值源。
- `technical-architecture.md` 定义工程分层和实现约束，不覆盖本文的玩法流程。

## 角色系统

- 游戏刚开始必须填写玩家昵称和大学名称，二者没有默认值；填写完成后写入统一 `GameState`。
- 玩家昵称和大学名称只用于称呼、存档、固定剧情、个性化文本和排行榜展示，不提供数值加成，不参与结局门槛。
- 完成开局档案填写后，才进入角色抽取与选择流程。
- 开局随机 `1` 张角色卡
- 玩家可免费重抽 `2` 次
- 最终选择 `1` 张角色卡开始游戏
- 免费重抽后不能返回上一张候选卡，且重抽结果不包含本轮已展示过的角色
- 选定角色后，`GameState` 必须记录 `selectedCharacterId`、学历背景和家庭背景
- 角色 ID、学历背景 ID 和家庭背景 ID 使用稳定内部枚举；正式游戏界面只展示中文角色名、中文学历背景和中文家庭背景，内部 ID 不直接暴露给玩家
- 角色卡等级用于开局抽取页展示和抽取稀有度；等级与抽取权重统一读取 `numbers.md`，不反向改变角色属性、学历背景或家庭背景
- 角色额外记录学历背景，用于塑造开局差异与部分路线语境，不提供直接数值加成
- 角色额外记录家庭背景，用于决定初始金钱、生活费发放和每周自动花费，不额外影响压力、路线成功率或事件权重
- 每个角色固定拥有：
  - 初始精力
  - 初始压力
  - 初始金钱
  - 六项角色属性
  - `1` 个被动特质
  - `1` 个专属技能

规则收束：

- 所有角色初始精力固定为 `100`
- 初始压力只读取角色表，不由家庭背景、学历背景或其他修正叠加
- 初始金钱只读取家庭背景表，并等于该家庭背景的 `1` 次月生活费
- 不新增额外行动槽
- 不新增角色专属资源
- 角色卡展示被动特质与专属技能的名称和效果摘要；内部触发次数、冷却和精确日志不要求在角色卡上完整暴露
- 被动特质尽量只修改既有数值规则
- 专属技能统一占用 `1` 次行动机会，统一冷却 `10` 周
- 专属技能使用后立刻进入 `10` 周冷却，第 `11` 周起可再次使用
- 压力高危时，专属技能仍只读取角色、冷却和技能自身门槛，不因压力高危额外禁用；若技能结算后压力达到失败阈值，按统一失败规则处理。

## 导师系统

- 军训结束后进行第一次导师选择
- 之后每个新学年重新选择导师
- 每次从 `3` 位导师中选择 `1` 位
- 不设置导师认可度
- 每位导师每学期给 `1` 个阶段任务
- 阶段任务只统计当学期行为、当学期课题状态和本学期属性成长量
- 新学期开始时阶段任务进度重置，不继承上学期的行动计数或任务完成状态
- 阶段任务统一在评图前结算
- 阶段任务只做“完成 / 未完成”判定，不做半完成档
- 阶段任务文本在学期第 `1` 周完整公开

导师影响固定为：

- 阶段任务
- 事件语境

### 阶段任务开放原则

- 早期学期不出现依赖高阶系统的任务
- 依赖 `竞赛投稿 / 名企实习` 等高阶系统的任务，只在对应系统已经开放后出现
- 不能要求玩家在“评图后”才能完成当学期任务
- 不能依赖当学期最终评图等级；如需表现“稳定通过”，只读取评图前可判定的过程指标或已完成学期记录

## 课题系统

每学期课题只保留两个临时值：

- 进度：`0-100`
- 作品质量：`0-100`

学期结束后清零。

例外：

- 大五上和大五下视为同一个 **毕业设计** 题目，共用累计进度与作品质量。
- 大五毕业设计进度与作品质量上限均为 `250`，大五上结束后不评图、不清零。
- 若 `我开摆了` 已发动，当前评图周期的进度值域上限直接减少 `10`：普通学期进度变为 `0-90`，大五毕业设计进度变为 `0-240`。
- 大五下最终答辩前毕业设计累计进度必须达到 `240 / 250`；若 `我开摆了` 已发动，本次门槛为 `230 / 240`。

进度主要来自：

- 正常速度画图
- 爆肝通宵赶图
- 部分随机事件
- 部分交互事件
- 部分专属技能

作品质量主要来自：

- 方案推敲
- 场地调研
- 模型周材料选择
- 模型周事件
- 部分随机事件
- 部分交互事件
- 部分专属技能

联动原则：

- `正常速度画图` 与 `爆肝通宵赶图` 主负责 `进度`；所有带 `基础进度` 的常驻行动都读取 `软件技术` 档位修正。
- 大五阶段，`正常速度画图` 与 `爆肝通宵赶图` 的最终进度收益在原基础上额外 `+4`，仍受状态风险收益削弱影响。
- 普通学期中，约 `7` 次正常速度画图应能补满进度；约 `5` 次爆肝通宵赶图应能补满进度，但状态代价显著更高。
- 事件、导师任务和角色技能允许造成进度加减，因此实际画图次数可以围绕目标压力浮动。
- `方案推敲` 与 `场地调研` 主负责 `作品质量`，并固定附带 `进度 +1`。
- 所有带 `基础作品质量` 的常驻行动都读取 `设计水平 + 创意审美` 的简单档位修正。
- 大五阶段，`方案推敲` 与 `场地调研` 的最终作品质量收益在原基础上额外 `+4`，仍受状态风险收益削弱影响。
- `方案推敲` 更偏室内高压深化，消耗精力并增加压力；`场地调研` 不设每周次数上限，更耗精力和金钱，并带来少量压力。
- 进度与质量合计不应吃掉整个学期；普通过关路线应能留下行动给学习、运动、放松、社交、兼职和突发补救。
- 画图速度与质量成长拆开处理，避免“快”与“好”在同一行动里同时滚满。

## 周行动系统

### 固定行动数

- 每周固定 `3` 次行动
- 不因角色、导师、被动、技能、副系统增加或减少
- 唯一例外为商店道具 `星巴克会员周卡`：购买后仅使`当前周`额外获得 `1` 次行动，总计 `4` 次，且同一周内此效果不叠加

### 不占行动次数的系统

- 选课
- 商店购物
- 模型周材料购买
- 竞赛投稿判定
- 实习申请判定
- 学期末课程题
- 学期雅思考试

### 开局固定流程

- 填写玩家昵称和大学名称、选择角色并开始游戏后，先进入 `开学典礼` 固定事件。
- 开学典礼结束后进入 `军训` 固定事件。
- 开学典礼与军训期间，所有周行动、商店、竞赛、实习、路线报名入口均不可使用。
- 开局固定事件仍走统一结算器和失败检查；若极端情况下触发失败，按统一失败规则读取。
- 军训结束后显示 `建院生活开始提示`。
- 建院生活开始提示就是大一的学年开始提示；该提示结束后，玩家从 `3` 位导师中选择 `1` 位作为大一导师。
- 导师选择完成后，选择大一年度课程；课程确认后，正式进入大一上第 `1` 周。大一不再额外显示独立的学年开始提示。

### 学年开始固定流程

- 从大二开始，每个新学年开始前，先从 `3` 位导师中选择 `1` 位作为该学年的导师。
- 导师选择完成后，选择本学年课程。
- 课程确定后显示学年开始提示弹窗。
- 玩家点击对应学年按钮（例如 `进入大二学年`）后，正式进入该学年上学期第 `1` 周。

### 音乐流程

- 玩家一打开网址，尝试从大一学年曲单第 `1` 首 `minecraft calm 1-main theme` 开始播放；若浏览器拦截自动播放，UI 提示玩家点击页面后恢复播放。
- 启动门加载页会阻塞预热大一上/大一下作品集展板和大一曲单首曲；其余大一曲目与失败结局绑定曲、其余作品集展板和结局图片在进入游戏后后台低优先级预热；大二到大五曲单、普通结束曲和歌词按既定时机继续预热。
- 大一曲单从开场页一路顺播到正式进入游戏；不因为进入开学典礼、军训或大一导师选择而停顿。
- 大一曲单播完后，在玩家尚未点击对应学年按钮前继续回到大一第 `1` 首循环，不提前切到后续学年 BGM。
- 未购买 `音乐会员` 时，学年 BGM 不提供手动切歌；只按该学年的既定顺序从前往后顺播，当前曲目播放完后自动切到下一首。
- 购买 `音乐会员` 后，玩家可以在当前学年 BGM 曲单内手动切到下一首；不能跨学年选歌，不能改变开头曲、结束曲、失败结局绑定曲或结局曲抽取规则。
- 学年曲单播放到末尾后，回到该学年的第 `1` 首继续循环。
- 玩家点击对应学年按钮时，切到该学年的第 `1` 首 BGM，并重置该学年的顺播顺序。
- 玩家重新开始新游戏时，音乐立即重置到大一学年曲单第 `1` 首并从头播放。
- 进入新学年开始提示页面时，立即切到下一学年第 `1` 首 BGM；玩家确认后继续沿用该学年曲单。
- 学年切歌、曲目自然切歌和结束曲开始播放统一使用渐入渐出。
- 曲目清单、文件名、时长和结束曲播放权重以 `../asset-work/music/README.md` 为准；结束曲弹窗、字幕和专辑表现以 `../asset-work/music/README.md` 为准。

### 尾声固定流程

- 大五下毕业设计答辩完成后，系统先完成结束曲抽取，再进入 `毕业典礼` 固定事件。
- 结束曲按玩家级已播放记录抽取：优先抽取该玩家尚未播放过的曲目；全部播放过一次后重置记录，并重新从完整曲池抽取。
- 指定失败结局可覆盖结束曲抽取，直接播放该结局绑定曲目；绑定表维护在 `../asset-work/music/README.md`。
- 进入 `毕业典礼` 固定事件后先停留在待开始状态；确认后依次进入两段毕业照，第二段毕业照确认后进入结尾回忆动画；玩家不能切换结束曲。
- 结束曲只跟随真正启动结尾回忆动画的按钮，不在毕业典礼或毕业照等待页提前播放。
- 如果结束曲播放完时玩家仍停留在结局流程中，则当前曲目从头循环播放。
- 结尾回忆动画开始时，左下角音乐框软入场；动画播放 `10` 秒后，音乐框用同一节奏向下渐隐退出。
- 结尾回忆动画进入最终结局页后，结束曲继续作为结局音乐播放；音乐框从动画内嵌样式切换到结局页样式时不能把曲目保持在暂停或静音状态。
- 中途失败不播放完整毕业回忆，直接进入对应失败结局。
- 完整毕业第一次进入结局流程时必须完整播放结尾回忆；从第二次结局流程开始，若全局记录已标记 `hasSeenEndingMemory = true`，可以显示 `跳过回忆` 按钮。
- 毕业失败延毕不触发毕业典礼或结尾回忆；评图结果页按钮显示 `恭喜你同学，你被延毕了！`，点击后直接进入 `毕业失败——你被延毕了！` 结局页面。
- `senior-test-copy` 是大五测试副本，渲染结尾动画测试时强制按 `hasSeenEndingMemory = true` 展示跳过按钮，不写入正式图鉴记录。
- 点击 `跳过回忆` 后不跳过结局结算，只跳过结尾动画；若结束曲已经播放，则在 `600ms` 内淡出后进入结局系统。
- 结束曲开始播放时，显示一次歌曲介绍软弹窗；弹窗自动渐出，不阻塞毕业典礼。
- 结束曲播放期间，若存在授权歌词字幕文件且该曲允许字幕，则在游戏舞台内部的相对顶部显示同步字幕；结尾回忆动画页无论是否显示跳过按钮，歌词统一定位为 `env(safe-area-inset-top, 0px) + clamp(70px, 8.6%, 104px) - 45pt`，但最终位置不得高于 `safe-area + 12px`；字幕必须跟随游戏舞台缩放，不能使用脱离舞台的视口偏移；开头曲、中间 BGM 和指定为无字幕的失败结局曲不显示歌词。
- 结束曲可展示像素风专辑图，并在播放中执行旋转效果；专辑图资源读取 `../asset-work/ui-icon-final/confirmed-ui-rules.md`，缺失时显示统一像素占位。
- 毕业典礼进入两段毕业照，再进入结尾回忆动画；动画完成或允许跳过后，触发统一结局系统。
- 结尾回忆动画由 `hyperframes/ending-memory/` 嵌入播放，逐帧读取优化后的 WebP；它只影响尾声表现，不参与属性、金钱、课题或路线结算。
- 毕业典礼不再结算属性、金钱、课题或路线结果，只承担尾声表现与情绪收束。

### 行动次数限制

- `接设计外包` 达到至少 `1` 个外包项目门槛后即可选择，每周最多 `2` 次；`Rhino曲面建模【精细】 / 一条龙方案代工` 各占用 `2` 次周行动，其余外包项目占用 `1` 次周行动；每周次数上限、导师任务和成就统计按承接项目次数计算。
- `校外兼职` 无能力门槛，每周最多 `2` 次；每次都正常占用 `1` 次周行动，并在兼职项目表中选择具体项目结算。
- 精力/压力高危仍可禁用 `接设计外包 / 校外兼职`，高危限制优先级高于每周次数上限；金钱高危只做风险提示。

### 行动可用性

所有行动入口统一由可用性解析器判断。

解析结果只允许三类：

- `可用`：玩家可以直接选择。
- `置灰`：入口可见，但因资源、阶段、高危状态、路线正式参与互斥或次数限制暂时不可用，并显示原因。
- `隐藏`：当前阶段不应展示该入口，例如未开放路线或已关闭的万里路入口。

UI 不直接复制条件逻辑，只展示解析器返回的状态和原因文案。

### 汇报策略

- 汇报策略只在评图阶段选择
- 不提前展开为独立主玩法
- 汇报策略不再修正 `进度` 或 `作品质量`
- 汇报策略在基础图纸评级产生后结算，只影响最终图纸评级、作品分和设计课绩点
- 汇报成功率由策略固定值决定，属性只作为可选门槛
- 汇报策略只读取策略自身门槛、基础图纸评级、当前精力和当前压力；导师不对汇报策略提供额外加减分。
- 进度未达硬门槛导致的 `F` 不能被汇报策略补救，最终评级保持 `F`、作品分固定为 `0`；已选择策略的压力或精力代价仍正常结算。
- `求求你别挂我` 只在进度硬门槛已达成、基础图纸评级因质量不足为 `F`，且此时满足 `质量评图分 < 60 且精力 < 60` 或 `质量评图分 < 60 且压力 > 50` 时可选；进度不足或其他非质量原因导致的 `F` 不展示该策略。
- `直接念 PPT` 永久无门槛，所有进入汇报策略选择的情况都可以选择。
- `我就是大师` 和 `高级技术流` 只读取各自展示的属性门槛；基础图纸评级为质量不足的 `F` 时仍可选择，成功时按正常升档升至 `D`，失败时仍为 `F`。
- 汇报策略完成后，UI 先显示汇报成功或失败，不提前揭晓最终评级；玩家确认后，再展示最终图纸评级与作品分。
- 汇报策略结果为“汇报失败”时，结果 UI 标题图标使用 `/optimized/asset-work/ui-icon-final/unmapped-icons/UIATLAS_001_基础操作按钮/UIATLAS_001_020_pxui_base_020_叉.d3ec4d59a5f9.webp`。

### 高危状态行动限制

当进入高危状态时，行动界面必须提示玩家当前风险，并限制部分行动选项。

- 精力高危：`精力 < 30`
- 压力高危：`压力 > 80`
- 精力高危时，禁用 `爆肝通宵赶图 / 接设计外包 / 校外兼职 / 万里路 / 实习申请` 等高精力消耗或持续消耗入口。
- 压力高危时，禁用 `方案推敲 / 场地调研 / 正常速度画图 / 爆肝通宵赶图 / 接设计外包 / 校外兼职`；专属技能不因压力高危额外禁用；交互事件选项不禁用，但会增加压力的选项必须显示红字风险提醒，提醒自动出现并自动淡出。
- 商店商品不读取精力高危、压力高危或金钱高危状态；可购买状态只受阶段、商品限购和当前余额约束，余额不足时置灰并显示原因。
- 精力高危与压力高危同时存在时，分别叠加两类高危限制；未被任一规则命中的行动仍可执行，且至少保留 `休养生息`，避免玩家无行动可选。
- 高危限制只限制行动选择，不直接触发结局；结局仍按失败阈值在结算节点读取。
- 轻度风险时，行动产生的正向 `进度 / 作品质量 / 六项属性` 各自 `-1`；不做四舍五入，不把 `0.5` 抬高为 `1`，若扣减会吞掉原本的正向小数收益，则保留原收益。
- 高危时，行动产生的正向 `进度 / 作品质量 / 六项属性` 各自 `-2`；不做四舍五入，不把 `0.5` 抬高为 `1`，若扣减会吞掉原本的正向小数收益，则保留原收益。
- 若玩家选择的行动或事件选项在结算后导致精力小于 `0`，不额外弹出风险确认，直接触发 `被迫停学`。
- 首次进入状态高危时弹出提示：`你正在崩溃边缘，别画图了，快去休息！`
- 若当前金钱低于该角色下周自动生活费扣费额，触发金钱高危提示：`你快要饿死了，省着点花！`
- 金钱高危只做预警，不强制禁用一般带花费行为；余额不足时，周行动、模型材料和万里路等风险执行入口必须显示风险提醒。常驻商店和 IELTS 报名按各自入口规则禁用。金钱小于 `0` 时才读取 `生活费断裂`。

## 评图系统

评图阶段不再触发普通随机事件。

评图采用“导师任务揭示 + 进度硬门槛 + 基础图纸评级 + 汇报策略修正最终评级”的流程。

评图 UI 顺序固定为：

1. 导师任务完成情况 UI：显示当前导师任务完成 / 未完成、奖励或处罚结算，不显示最终评级。
2. 汇报策略结果 UI：显示汇报成功 / 失败和对应简介，不显示最终评级。
3. 最终成绩 UI：揭晓最终图纸评级与作品分。

进度硬门槛：

- 大一至大四每学期课题进度上限为 `100`；评图前进度未达到 `90` 时，本次评图直接为 `F`，不可用汇报策略补救。
- 大五上不设置正式评图；毕业设计进度和作品质量继续累积到大五下。
- 若 `我开摆了` 已发动，当前评图周期的进度上限和进度硬门槛都减少 `10`；普通学期评图门槛变为 `80 / 90`。
- 大五下为毕业设计答辩；毕业设计最终进度未达到 `240 / 250` 时，视为未完成毕业设计。若 `我开摆了` 已发动，本次门槛为 `230 / 240`。

质量硬门槛：

- 大一至大四作品质量对应 `0-100` 的质量评图分；质量评图分 `0-59` 时，基础图纸评级为 `F`。
- 大五毕业设计作品质量按累计 `0-250` 记录，最终答辩时折算为 `0-100` 的质量评图分；折算后 `0-59` 时，基础图纸评级为 `F`。
- 大五原始作品质量的等价评级区间为：`S = 250`，`A = 225-249`，`B = 200-224`，`C = 175-199`，`D = 150-174`，`F = 0-149`。
- 基础图纸评级先由作品质量评图分决定。
- 汇报策略不改变作品质量，只在基础图纸评级之后改变最终图纸评级、作品分和设计课绩点。
- 导师阶段任务和部分事件只允许在评图前修正作品质量、状态或 GPA，不再产生独立“评图总分”。

评图等级固定为：

- S
- A
- B
- C
- D
- F

等级、设计课绩点和质量评图分固定对应为：`S = 4.0 / 100`，`A = 3.7 / 90-99`，`B = 3.2 / 80-89`，`C = 2.4 / 70-79`，`D = 1.3 / 60-69`，`F = 0.0 / 0-59 或进度硬门槛未达成`。

规则：

- `D` 视为过关
- `F` 视为挂科
- 每次评图结束后，系统必须在最终成绩 UI 中告诉玩家本次最终图纸评级是 `S / A / B / C / D / F` 中的哪一档，并显示本次作品分。
- 累计 `2` 次 `F` 直接触发 `挂科两次被劝退`；若累计第 `2` 次 `F` 发生在大五下毕业设计答辩且毕业设计未完成，则优先读取 `毕业失败——你被延毕了！`

## GPA 系统

- 个人 GPA 显示值和路线读取值范围：`0.0-4.0`
- 开局显示 GPA：`未知`
- 未完成任何学期评图且没有个人 GPA 直接修正前，个人 GPA 不参与后期路线读取。
- 非 `F` 学期由最终评图产生的设计课绩点叠加本学期 `GPA学期修正`，再计入个人 GPA 平均值。
- `F` 学期计入绩点固定为 `0.0`，并记录为挂科，不吃正向修正。
- 个人 GPA 平均结果超过 `4.0` 时仍显示并读取为 `4.0`；平均结果低于 `0.0` 时仍显示并读取为 `0.0`。
- `F` 仍然记录为挂科。
- `GPA学期修正` 只在评图后改变本学期计入绩点；`个人 GPA 直接修正` 立即改变个人 GPA 显示值和路线读取值，并在后续评图重算时继续保留。
- 大学课程是最稳定的 `GPA学期修正` 来源；少数导师阶段任务和事件也可以写入该修正；明确写作 `个人 GPA` 的角色技能使用直接修正。
- GPA 服务于后期路线，不反向改变每周行动结构

## 大学课程系统

- 每学年开始可从课程目录中选择 `1` 门课
- 课程选择不占每周行动次数
- 大学课程不做独立玩法
- 大学课程的作用固定为：
  - 属性收益
  - 事件语境
  - GPA 学期修正

学年下半学期第 `5` 周结束：

- 回答 `3` 道对应课程题
- 直接结算课程修正
- 答题过程中不显示单题对错，也不显示正确答案；玩家选完后直接进入下一题
- 每道课程题出现后，题页右上角显示 `30` 秒倒计时；倒计时结束仍未作答时，该题判错并自动进入下一题或考试结算；时钟图标使用 `003_游戏主要过程界面时钟图2__时钟图2.414900d928ef.webp`
- 全部题目结束后，只显示本次总结果和对应 GPA 修正

## 金钱与生活费

生活费每学期发放 `2` 次：

- 第 `1` 周
- 第 `4` 周

大一上第 `1` 周不发生活费；从大一上第 `4` 周开始正常按发放规则结算。

每次发放对应家庭背景的 `1` 次月生活费。

每周自动花费固定结算。

每周自动花费按家庭背景固定为：贫寒 `350`、普通家庭 `600`、富二代 `2500`、院士子女 `1500`。

规则收束：

- 金钱是强约束资源
- UI 只显示余额数值，不把金钱做成进度条。
- 除常驻商店和 IELTS 报名外，余额不足时一般带花费行为不强制禁用，只显示风险提醒
- 不做债务系统
- 任意结算后金钱小于 `0`，立即触发中途失败结局 `生活费断裂`
- 金钱等于 `0` 不触发 `生活费断裂`，但继续进行带花费行为必须展示可能扣成负数的提示
- 避免出现不可控的“强制扣费直接判死”文本事件；强制流程如模型材料选择也必须先展示扣费风险

### 每周自动恢复

- 每周所有行动、事件、商店、实习和自动花费结算完成后，统一执行基础周恢复：`精力 +10`、`压力 -5`
- 任意结算后压力达到 `100`，立即触发中途失败结局 `压力失控——好好休息，同学`。
- 压力失控的连续周计数读取周结算后、基础周恢复前的压力状态；若压力 > `90` 连续 `2` 周，也触发 `压力失控——好好休息，同学`。
- 周恢复固定存在，不因 `模型周 / 赶图周 / 考试周 / 毕业设计阶段` 改变
- 周恢复后仍处于高危状态时，只保留高危行动限制，不额外追加兜底恢复

## 商店系统

商店为常驻轻量系统，不占行动次数。

定位：

- 补状态
- 小修正
- 轻量抗风险

边界：

- 不做库存
- 不做耐久
- 不做背包
- 不做 build 系统
- 强功能商品按学期限购
- 商店商品只改数值，不改已经确定的商品内容和商品数量
- 消耗型补给按周限购，成长型商品按学期限购，强功能商品按学年或学期限购
- 商店只能做轻量成长和风险修正，不能替代行动系统成为主养成渠道
- 永久型、一学期型与一学年型商品效果，都在对应结算点自动读取
- 商店商品可购买状态不读取高危状态；除阶段不可用外，只按限购和当前余额判断，余额不足时置灰并显示原因。
- 常驻商店购买成功后立刻写入日志框的 `购买日志` 分类；商店购买记录不混入 `行动日志`、`事件日志` 或 `成就日志`。
- 商店长期周恢复类效果合计每周最多生效：精力 `+3`，压力 `-5`；超过上限的部分在周结算时截断。该上限只限制商店长期效果，不限制基础周恢复。
- `星巴克会员周卡` 是唯一允许临时增加当前周行动次数的商店商品
- `星巴克会员周卡` 同一周只能购买 `1` 次；购买后本周入口置灰，避免重复扣费但不叠加。
- `疯狂星期四` 每周限购 `1` 次。
- `红牛` 每周限购 `1` 次，定位为高精力恢复、高压力增加的冲刺补给。
- `眼药水` 每学期限购 `1` 次，购买后本学期每周固定小幅恢复精力并降低压力。
- `健身房年卡` 价格固定为 `1600`，每学年限购 `1` 次。
- `健身房年卡` 本学年内把精力临时上限提高到 `105`，并只修正 `健身运动` 的精力消耗；不增加行动次数，也不把商店变成主养成渠道。
- 不设置推荐商店；商店只展示完整商品清单、分类和可购买状态。

## 模型周材料购买

- 模型材料不属于商店系统，不出现在常驻商店里。
- 模型材料购买不归入常驻商店的 `购买日志`，仍按模型周流程记录。
- 除大五上外，每个模型周开始时强制弹出模型材料选择 UI。
- 玩家必须从 `手工切割 / 激光切割 / 3D打印` 中选择 `1` 种材料方案。
- 模型材料选择不占行动次数；选择后立刻扣钱并结算，然后才进入本周事件与行动。
- 每个模型周只能选择 `1` 次模型材料；选择完成后，本学期不能改选、补买或重复购买。
- 余额不足时不置灰材料方案，只显示扣费风险；选择后正常扣钱并按统一金钱失败规则结算。
- 模型材料的具体数值与模型周事件权重修正以 `numbers.md` 为准。

## 事件系统

事件文档按“自动随机事件体系 + 固定流程事件 + 主动地点事件 + 实习期间短事件”组织。

自动随机分池固定为：

- 普通随机事件
- 交互事件
- 模型周事件

万里路事件由“建筑生的万里路”主动入口按固定地点顺序触发，不进入自动随机分池。

固定流程事件由状态机直接触发，实习期间短事件由实习周次读取，二者不进入自动随机分池。

课堂事件与导师偏移仍作为语境标签，不单独开池。
不再设置 `周结算事件`；一周结束时若需要保底触发，只从普通随机事件或交互事件中抽取。

### 触发原则

随机事件采用：

1. 先判定本周触发次数
2. 再判定事件池
3. 再按权重抽取

事件数量、学年目标、分池比例、连续触发目标和阶段权重统一维护在 `numbers.md` 的“事件权重与次数目标”。`systems.md` 只保留流程口径：

- 普通正式周最多展示 `1` 次自动事件，普通随机事件、交互事件、模型周事件和实习期间短事件共用该上限。
- 实习期间短事件或模型周事件发生当周占用本周唯一自动事件名额；不再按剩余名额补普通随机事件或交互事件。实习期间短事件必须显示阻塞事件弹窗，不能只进入事件日志。
- 随机事件每周最多触发 `1` 次；连续周是否触发只由阶段限定、冷却、保底和权重决定。
- 大一上前两周的随机事件只在一周行动后结算触发；大一上第 `3` 周起，随机事件可在一周行动中间或周结算触发。
- 模型周事件只在模型周触发，模型周总共 `9` 次，其中固定 `6` 次触发：大一上、大一下、大二上、大二下、大三下、大四下。大五上第 `5` 周不触发模型周事件，改为大五感动事件权重周。
- 第一学期第一周保留 `1` 次强制随机事件，作为首次事件教学。
- 万里路事件由玩家主动前往地点后必定触发，不进入自动随机分池，不计入普通正式周唯一自动事件名额。
- 前期更容易触发日常与交互事件，后期逐步降低打断感。
- 固定流程事件、暑假写生节点和万里路事件不计入单局随机事件目标；实习期间短事件实际发生时计入单局目标，并占用普通正式周唯一自动事件名额，但不进入自动随机分池。
- 阶段限定事件必须读取事件配置中的 `semesterMin / semesterMax` 或 `EVENT_PHASE_OVERRIDES`；同名中文标题不作为规则判断键。
- 玩耍娱乐类交互事件单局保底触发 `2` 次弹窗；保底只保证事件出现，不强制玩家选择娱乐选项。
- 暧昧类事件在大一下至大二下开放，且与歌曲无关。`hasPartner = false` 时进入抽取；大一下保底触发 `1` 次且最多 `1` 次。`hasPartner = true` 后暧昧、搭讪和恋爱推进类事件停止抽取；从触发 `两情相悦` 的事件之后开始计数，第 `2` 次事件弹窗必定为 `恋爱危机`。
- AI 相关事件单局保底 `2` 次、目标 `3` 次、软上限 `3` 次；保底只从 `tags` 包含 `ai` 的普通随机事件和交互事件中读取，同一 `id` 不重复计入。该保底只保证 AI 语境出现，不等同于获得 `AI 相关经历`。
- 大四自动随机事件按焦虑类目标占比 `80%` 加权；大五自动随机事件按感动、回忆和成长类目标占比 `80%` 加权。占比是调参目标，不突破阶段限定、冷却、互斥和保底规则。

### 结构原则

- 每条事件必须可落在既有系统内
- 不新增隐藏主数值
- 事件默认不直接改 `GPA / 作品集 / 个人简历 / 竞赛结果`
- 自动随机事件体系内，所有带选项事件统一归入交互事件；暑假写生是固定交互表现，路线确认弹窗是系统流程。
- 跨局历史耗尽后只回到 `repeatable !== false` 的候选，非重复事件不进入兜底重复

### 结构化字段

事件配置字段口径统一维护在 `numbers.md` 的“程序落地格式”。流程层只要求：

字段规则：

- 标题重复不视为错误，但 `id` 必须唯一
- `id` 发布后保持稳定，标题和文案可以调整，程序主键不随文案变化
- `tags` 不新增玩法，只服务权重、冷却和内容筛选
- `contextTags` 是语境，不是新事件池
- `triggerRules` 只描述触发条件与覆盖规则，不承载文本内容与数值结果
- 普通随机事件不写 `options`
- 交互事件不写隐藏概率树，只写显式选项

### 重复与冷却

- 同一局内已触发过的自动随机事件不会再次进入候选。
- 跨局历史避重作用于普通随机事件和交互事件；只要当前候选中仍有未玩过的事件，就优先排除历史已玩过的事件；当前候选都已玩过时，不清空历史记录，但回到当前阶段所有 `repeatable !== false` 的候选作为兜底重复。
- 同标题 `4` 周内不重复
- 首版事件筛选读取结构化字段 `baseWeight / cooldownWeeks / repeatable / semesterMin / semesterMax / tags`；语义重复与同类过密暂不另设公式。

## 建筑生的万里路

- 大二上开始开放，开放后不再按学年关闭；一学年最多前往 `6` 次，金钱不足时前往按钮置灰并显示余额不足状态
- 大二上第 `3` 周结算完成后、进入第 `4` 周前，弹出万里路开放提醒 `你该走出专教了！`
- 前 `6` 个地点每次消耗 `1` 次行动机会，后 `6` 个地点每次消耗 `2` 次行动机会；当前周剩余行动次数不足本次行动消耗时仍可前往，超出的行动次数从下一周行动次数中扣减
- 前 `6` 个地点每次额外消耗金钱 `2500`，后 `6` 个地点每次额外消耗金钱 `4000`；入口在已借用下周行动次数、达到学年次数上限、流程不可用或余额不足时置灰

- 玩家按固定顺序推进地点，不随机跳点
- 玩家选择前往当前地点后，先弹出对应万里路事件；事件弹窗的结算按钮确认后才消耗行动次数、扣费并写入旅行记录
- 万里路事件的单次数值收益读取 `numbers.md` 的“万里路事件结算表”，用来匹配对应地点行动成本和旅行成本
- 万里路事件不计入普通正式周唯一自动事件名额
- 第一次在模型周或赶图周使用万里路时，触发成长成就 `忙里偷闲`
- 完成全部 `12` 个地点后，万里路入口关闭
- 万里路只进入简历与成长路径，不进入作品集

## 暑假写生系统

- 只保留 `1` 个固定节点
- 不占普通周行动次数
- 只提供属性与事件收益
- 不设置单独失败条件
- 写生节点没有专属失败剧情；但选项结算仍走统一失败检查，若精力、压力或金钱打穿全局失败阈值，直接读取对应统一失败结局。
- 采用固定交互事件表现，但不进入普通 `交互事件` 随机池，也不计入单局随机事件目标。
- 大二下学期结束后固定触发 `暑假写生`，玩家在 `江西婺源——马克笔训练` 与 `安徽宏村——水粉训练` 中选择 `1` 个地点。
- 写生选项结果统一走结算器；具体文本见 `events.md`，数值见 `numbers.md`。

## 作品集、竞赛、简历

### 作品集

- 作品集只保留一个总分，不拆子分。
- 作品集总分不进入游戏主过程 HUD，只在作品集、路线、结算或详情类面板中展示。
- 作品集总分不设固定上限，首版按约 `0-900` 的体感区间校准。
- 作品集总分由已完成且最终图纸评级为 `C` 及以上课题的作品分累加形成。
- `D / F` 评级作品不进入作品集；`D` 仍视为课程通过，只是不作为作品集成果。
- 大一至大四每次正式评图结算后，只有最终评级为 `C / B / A / S` 的作品入库；大五毕业设计只在大五下最终答辩后按同一门槛入库 `1` 次，大五上不评图、不入库。
- 竞赛、实习、万里路、商店和课程不直接增加作品集总分。

### 竞赛

- 竞赛素材只来自课程设计作业
- 只有满足对应赛事门槛的作品可以投稿
- 竞赛每学期最多投稿 `1` 次
- 投稿次数按当前游戏学期计算，不按作品来源学期计算
- 满足投稿门槛但未投稿的作品会保留为可投稿作品，直到被投稿使用或毕业结算结束
- 同一作品只能投稿 `1` 次；这里的“作品”默认指一份已完成的课程设计作业
- 同一课题不能重复投向多个竞赛，本质上等同于“单作品唯一投稿”
- 奖项只保留：
  - 未获奖
  - 三等奖
  - 二等奖
  - 一等奖
- 竞赛不直接增加作品集
- 图纸等级只作为竞赛投稿门槛；获奖概率直接读取作品分
- `S` 级作品投稿对应赛事时必定获得一等奖；其他可投稿作品分区间均保留未获奖概率
- 竞赛可产生奖金，但奖金不反向增加作品集分数
- 竞赛结果在投稿后立即公开，不受学期结算时点限制
- 玩家可以随时查看自己的竞赛投稿记录与获奖情况
- 首次有 `C / B / A / S` 作品入库后，记录竞赛投稿提醒到期周为当前周 + `12`；到期时若玩家仍未完成任何竞赛投稿，弹出一次标题为“竞赛投稿提醒”的系统提示。
- 竞赛投稿 UI 将 `赛事目录` 与 `投稿记录` 作为同级导航；点击赛事卡后，在目录下方展示该赛事当前可投稿作品，没有符合条件的作品时显示空状态；本学期已投稿时显示“本学期已投”，对应文字和 UI 框使用红色。
- 竞赛结果写入个人简历时只记录“赛事名 + 奖项 + 当次获奖经历”，不做简历总分
- 竞赛固定读取四项指定赛事：`霍普杯国际大学生建筑设计竞赛 / 台达杯国际太阳能建筑设计竞赛 / 台湾国际学生创意设计大赛 / 东南·中国建筑新人赛`
- `东南·中国建筑新人赛` 只允许大一至大三参加。
- 竞赛结果公开时必须弹出结果 UI，只显示奖项和对应结果文案；获奖时按钮显示统一奖金提示：`恭喜你！荣获{amount}¥的竞赛奖金！`。
- 竞赛结果为“未获奖”时，结果 UI 标题图标使用 `/optimized/asset-work/ui-icon-final/unmapped-icons/UIATLAS_001_基础操作按钮/UIATLAS_001_020_pxui_base_020_叉.d3ec4d59a5f9.webp`。
- 竞赛进入个人简历和成长成就的记录仍在后台结算，但不再单独弹出“简历写入提示”或“竞赛成就提示”。

- 不做简历总分系统
- 不允许玩家编辑规则经历文案

## 后期路线

大一至大四提供后期路线入口，但入口只展示候选方向、条件说明和大五开放提示，不记录任何后期路线状态，也不能形成正式参与。大五上第 `1` 周起，所有后期路线正式参与入口全部开放展示，但不弹出提示弹窗，不显示红点或催促 UI。只有大五阶段玩家主动完成路线报名、申请、投递、考试或确认后，才形成“路线正式参与”记录。

规则：

- 未正式参与方向时，玩家仍可继续周行动、实习申请、竞赛投稿、商店和常规推进。
- 未正式参与方向时，路线报名、路线考试、路线投递和路线申请不会自动发生。
- 若玩家直到毕业仍未正式参与任何后期方向，结局系统跳过路线结果，读取普通状态毕业结局。
- 路线正式参与后不能改选，也不能跨方向补报名。
- 每局最多正式参与 `1` 个后期方向。
- 可正式参与方向为：`保研 / 考研 / 留学 / 选调 / 考公 / 考编 / 建筑工作 / 转行`。
- 大五上第 `1` 周起，全部正式参与入口都可见；入口是否可点击只由阶段、门槛、资源、高危状态、互斥和次数限制决定。
- 如果玩家在大五上第 `1` 周暂不选择正式参与路线，后续周次入口仍常驻可见，不记录选择，也不触发提醒或催促。
- 路线正式参与最晚必须在大五下毕业设计答辩前完成；毕业设计答辩开始后，所有未选择的后期路线入口关闭。
- 正式参与路线后不能放弃路线回到“未正式参与”状态；只有确认弹窗取消、创业契约放弃这类尚未写入正式参与记录的操作可以回到未锁定状态。
- 选择 `转行` 时必须同步选择具体转行岗位，结局触发必须读取这个具体岗位。
- 选择 `选调 / 考公 / 考编` 时必须同步选择 `1` 个具体岗位或岗位层级；只能读取该体制内方向和已确认岗位，不能在结算时互相串线或改读其他岗位。
- 选择 `考研 / 选调 / 考公 / 考编` 后，后续若考试或复试未过线，只读取该方向的失败或回落结局，不再跳到工作、转行或其他路线。
- 选择 `建筑工作` 后，必须同步确认 `1` 个投递岗位；只读取该岗位成功结局或求职待定，不读取其他建筑岗位、转行岗位或升学结局；是否求职成功由投递时锁定的内部判定决定，不提前公开，只在最终结局结算时揭示。
- 选择 `保研 / 留学` 后，只读取对应复试或申请结果；失败后不自动切换到考研或工作成功结局。
- 正式参与 `保研` 时必须同步确认申请档位：`梦中情校`、`建筑老八校 / 其他 985`、`本校 / 211` 三档之一。
- 正式参与 `考研` 时必须同步确认报考档位：`梦中情校 / 建筑老八校 / 其他 985、211 / 普通一本院校` 中的对应档位。
- 正式参与 `留学` 时必须同步确认申请院校。
- 正式参与 `选调` 时必须同步确认岗位为 `生源地选调生`；正式参与 `考公` 时必须同步确认 `国家部委层 / 省市厅局层 / 基层公务员` 之一；正式参与 `考编` 时必须同步确认 `教师岗 / 事业单位综合岗 / 行政管理岗` 之一。
- 考公三个岗位层级由玩家在正式参与考公时主动选择；允许直接选择 `基层公务员`，系统不按数值自动推荐、自动升档或自动降档。
- `选调 / 考公 / 考编` 三者只能正式参与其中 `1` 个；对应岗位或岗位层级也只能确认 `1` 个，确认后不能改选或补选。
- `选调 / 考公 / 考编` 若失败，必须读取对应回落结局，不读取状态毕业结局。
- 选择 `转行` 后，只读取对应转行岗位结果；是否转行成功不提前公开，只在最终结局结算时揭示。
- `转行` 下的 `创业` 是特殊高门槛入口：只有六项角色属性全部 `>= 80` 时才可选择；未满足时入口置灰并显示缺失属性。
- 玩家选择 `创业` 且满足门槛后，先弹出交互弹窗 `恶魔的契约`。玩家选择签下契约后立即形成路线正式参与记录并锁定创业结局，不再弹出路线确认或等待结果提示；选择放弃等同于取消本次选择，不锁定路线，不写入转行失败。
- 路线考试、申请、投递和内部判定结果只写入内部状态与日志，不提前展示给玩家。
- 留学申请提交、建筑工作投递、非创业转行投递前必须满足对应入口门槛；未满足门槛时入口置灰，不形成正式参与记录，也不写入失败。
- 留学申请提交、建筑工作投递、非创业转行投递会在当次操作时锁定内部判定结果；留学按已确认申请院校的档位基础概率、雅思余量、作品集余量和 GPA 余量计算，判定概率统一维护在 `numbers.md`；后续属性、GPA、作品集、竞赛、实习或 AI 相关经历变化不重算该结果。
- 已正式参与非留学路线后，若当学期雅思机会未使用，仍可参加雅思；雅思成绩只作为记录保留，不改变已正式参与路线。
- 雅思答题过程中不显示单题对错，也不显示正确答案；每道雅思题出现后，题页右上角显示 `60` 秒倒计时；倒计时结束仍未作答时，该题判错并自动进入下一题或考试结算；时钟图标使用 `003_游戏主要过程界面时钟图2__时钟图2.414900d928ef.webp`。
- 玩家完成当次路线考试（保研复试、考研初试、考公、考编、选调）、提交留学申请、完成建筑工作投递或完成非创业转行投递后，统一弹出等待结果提示；创业契约签下后不弹出等待结果提示。文案读取 `content-plan.md` 的“路线等待结果弹窗文案”。
- 最终路线结果必须由统一结局解析器读取，其他系统不能提前写死人生结局。

路线正式参与入口未满足门槛时，入口置灰并展示缺失条件；未满足门槛只停留在候选不可点击状态，不形成正式参与记录，也不写入路线失败。满足门槛的考试、报名、申请和投递路线都先进入对应路线确认弹窗；确认后才形成路线正式参与、路线考试、申请、投递或内部判定。

正式参与任意路线后，其他路线入口关闭；UI 可保留入口但必须置灰，并提示已选择的正式路线。大五学年已正式参与路线后，`考研升学 / 申请保研 / 出国留学 / 转行` 的页面标题旁统一显示 `已正式参与xxxx`：已确定路线对应入口使用蓝色文字和边框，其他相关入口使用红色文字和边框，`xxxx` 读取正式参与记录的路线标签。建筑工作与转行的简历投递只能投 `1` 个地方。正式参与路线后，周行动、商店、实习申请和竞赛投稿仍可继续，除非被阶段、资源、高危或其他既有规则限制。

大五阶段所有路线正式参与前，UI 都弹出对应路线确认提示。`建筑工作` 或 `转行` 的非创业岗位简历投递确认文案读取 `content-plan.md` 的“路线投递确认弹窗文案”；保研、考研、留学、选调、考公、考编读取命令层对应的路线确认弹窗。`创业` 不属于简历投递，只弹出 `恶魔的契约` 二选一确认。

路线确认弹窗中选择取消时，不形成路线正式参与记录，不消耗报名、考试、申请或投递机会，也不写入路线失败。

路线组固定为：

- 升学路线组
- 体制内路线组
- 建筑工作路线组
- 转行路线组

### 路线收束原则

- 保研与考研归入升学路线组
- 考公、考编、选调归入体制内路线组
- 建筑工作和转行在大五阶段通过投递或确认形成正式参与记录，再按该方向做结果判定
- 留学只做申请判定，不展开复试玩法
- 建筑工作失败后保留 `求职待定——回去等通知吧！` 兜底路径
- 所有成功路线最终只产出 `1` 个主结局
- 状态毕业结局是完整毕业、路线未成功且没有可读取方向专属回落时的最终保底

### 路线考试与答题

- 保研复试与考研初试共用 `升学专业题库`。
- 升学专业题库总量以 `question-banks.md` 当前题目数为准；每次最多抽取 `10` 道，优先 `6` 道简单题、`4` 道困难题，不足时按现有题量抽取并补足。
- 考公、考编、选调共用 `行测题库`。
- 行测题库总量以 `question-banks.md` 当前题目数为准；每次最多抽取 `10` 道，优先 `6` 道简单题、`4` 道困难题，不足时按现有题量抽取并补足。
- 路线考试答题过程中不显示单题对错，也不显示正确答案；玩家选完后直接进入下一题。
- 每道路线考试题出现后，题页右上角显示 `60` 秒倒计时；倒计时结束仍未作答时，该题判错并自动进入下一题或考试结算；时钟图标使用 `003_游戏主要过程界面时钟图2__时钟图2.414900d928ef.webp`
- 大五阶段正式参与 `保研 / 考研 / 选调 / 考公 / 考编` 后，若满足考试触发条件，则立即进入对应考试阶段；大五上正式参与不再等到大五下。
- 路线考试结束后只记录内部结果，不向玩家显示总分、答对题数、是否达线，也不提前公布成功或失败。
- 路线考试完成后，必须显示统一等待结果弹窗；文案读取 `content-plan.md` 的“路线等待结果弹窗文案”。
- 路线考试结果统一保留到大五下毕业设计答辩结束后的结局结算阶段再揭示。
- 升学与行测考试都采用“`10` 题隐藏答题结果 -> 内部折算成绩”的方式；具体折算分与分数线统一维护在 `numbers.md`。
- 进入大五下时，若 `保研 / 考研 / 选调 / 考公 / 考编` 入口门槛未满足，入口保持置灰并展示缺失条件；只有已正式参与且满足考试触发条件的路线才进入考试阶段。

### 毕业设计门槛

- 大五上和大五下均为毕业设计阶段，并共同承载同一个毕业设计题目。
- 大五毕业设计使用同一组累计进度与作品质量，两项上限均为 `250`；大五上结束后不评图、不清零。
- 大五上不设置正式评图和模型周；第 `5` 周原模型周位置改为大五感动事件权重周。
- 顺利毕业必须完成毕业设计。
- 毕业设计完成条件为：大五下毕业设计最终评图 `D` 及以上，且毕业设计最终进度达到 `240 / 250`；若 `我开摆了` 已发动，本次门槛为 `230 / 240`。质量不足导致的 `F` 若通过 `求求你别挂我` 成功补救为 `D`，视为完成毕业设计。
- 大五下毕业设计答辩结束后，直接触发结局系统结算，不再额外延后。
- 若完整读到毕业但未完成毕业设计，评图结果页确认后直接读取 `毕业失败——你被延毕了！`，不读取其他成功路线结局，也不播放毕业典礼或结尾回忆。

### 状态收尾

- 成功通关只追加 `1` 句状态收尾。
- 状态收尾只保留 `普通 / 沉重` 两类。
- 普通：通关时不满足沉重。
- 沉重：通关时 `精力 < 35` 或 `压力 > 75`。

### 强路线可达性

- 强路线指明显优于普通毕业的高门槛成功结局；具体分档与调参目标以 `numbers.md` 的“强路线稀有度”为准。
- 强路线不要求多数玩家自然达成
- 普通通关必须稳定可达
- `基层公务员` 属于普通可达成功路线，不纳入强路线稀有度目标。
- 强路线失败不导致中途失败，只读取该方向专属回落；若该方向没有专属回落且完成毕业设计，则读取状态毕业结局

## 失败与通关

### 中途失败

中途失败只保留四条：

- 生活费断裂
- 压力失控
- 挂科两次劝退
- 被迫停学

### 成功通关

- 只有完整读完五年、未中途失败且完成毕业设计，才算成功通关
- 成功通关只读取 `1` 个主结局 + `1` 句状态收尾

### 结局读取优先级

最终结局只在统一结局解析器中读取，优先级固定为：

1. 中途失败（大五下毕业设计未完成与累计第 2 次 `F` 同时发生时，按 `毕业失败——你被延毕了！` 处理）
2. 毕业失败——你被延毕了！
3. 已正式参与路线结果
4. 状态毕业

强路线只是高门槛成功结果，不是额外失败条件。

## 文档边界

- 具体数值写入 `numbers.md`
- 具体内容池写入 `content-plan.md`
- 具体事件写入 `events.md`
- 具体结局写入 `endings.md`
- 具体题库写入 `question-banks.md`
