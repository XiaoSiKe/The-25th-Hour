# 结尾回忆走马灯与结局图片匹配稿

本文先作为导演稿和 UI 资产对照表使用，不安装或依赖 HyperFrames 插件。素材来源：

- `web-app/optimized/assets/结尾回忆走马灯图片/`：普通走马灯场景使用 WebP 优化图。
- `web-app/optimized/assets/story-events/`：`毕业答辩`、`毕业典礼（报告厅）`、`毕业照`、`军训2`、`入学讲座`、`专教生活` 使用已优化的剧情事件 WebP；`毕业照（相册首页）` 使用走马灯目录下的独立 WebP。
- `结局图片/`：31 张 PNG。
- `docs/endings.md`：39 条人生结局总库。

## 动画目标

结尾回忆是固定播放的毕业记忆相册：从相册首页开始，按下表顺序播放 `108` 张图片，所有图片必须完整入屏，不做图片内人物或物件的独立动画。

当前实现以 `hyperframes/ending-memory/main.js` 为准，本文只维护可执行规格、素材顺序、时长和字幕。已调好的单张时长不在本文档收敛中再改动。

成片目标时长约 `164s`，允许实现误差 `±8s`。节奏主体分为 `11` 段：高考与离家、开学快闪、课堂与基础课、专教与赶图、模型与返工、宿舍与恋爱、朋友与演出、运动快闪、写生与出逃、实习与现实、告别与毕业；片头另以毕业照快门触发进入回忆。若目标时长与下方逐帧表冲突，以当前可执行表和 `hyperframes/ending-memory/main.js` 为准。

## 播放规格

| 项目 | 当前规格 |
|---|---|
| 根画布 | `2500x1275` |
| 图片显示 | `.photo-wrap img { object-fit: contain }`，不裁切 |
| 普通图框上限 | 非重点 `2200x1060`，重点 `2360x1090`，含安全边界自动缩放 |
| 快闪图框上限 | `1960x1000`，比普通图小一圈 |
| 快闪最短停留 | `0.8s`，沿用当前已调整时长 |
| 快闪可见堆叠 | 最多 `8` 张，旧图滑出窗口后设为 `visibility: hidden` |
| 快闪入场 | `0.28-0.38s`，`opacity 0 -> 1`，轻微位移、缩放、旋转 |
| 普通入场 | `0.68-1.24s`，`opacity 0 -> 1`，轻微位移、缩放、旋转 |
| 字幕入场 | 快闪 `0.24s steps(6)`；普通 `0.10-0.24s steps(4)` |
| 字幕退场 | 局部字幕 `0.18s` 渐出；底部字幕 `0.22s` 渐出 |
| 字幕生命周期 | 按字幕表 `字幕停留` 执行，到点渐出并消失，不拖到下一张 |
| 图片加载 | 前 `10` 张 eager，其余 lazy；前 `6` 张 high fetch priority，其余 low |
| 音乐 | 点击开场按钮后播放 `../../新版结束曲/主角.MP3`，不按歌词卡点 |

## 层级与性能口径

- 同屏最多保留 `8` 张快闪照片或 `3` 张普通旧照片；重点图旧照片深度为 `2`。
- 不再使用文档型 overlay 动效名作为实现要求，例如 `redline_overlay`、`blueprint_line`、`map_pin_overlay`、`whip_pan`、`flash_cut`。如果未来真要做这些效果，先落到代码再写入本文档。
- 旧照片离开可见窗口后必须隐藏，避免 108 张图片长期参与绘制。
- 图片只做整张容器的 `opacity`、`x/y`、`scale`、`rotation`；不做滤镜、shader、粒子、复杂遮罩或图片内部动画。

## 字幕出场顺序

字幕统一使用 `ArkPixel12ZhCn`（方舟像素字体 12px proportional zh_cn）作为主字体，`EndingMemoryManualPatch` 作为手工补字字体接在其后。当前已停用自动生成的 `EndingMemoryPixelPatch`，因为它和方舟字体风格差异过大；补字只覆盖主字体缺失的可见文字，不替换已有字形。

快闪字幕使用 `pixel_caption_pop`：`0.24s` 像素弹出、字号 `36px`、浅色文字、深色描边。字幕必须跟随照片可见时间，不能在照片还在时提前消失。
