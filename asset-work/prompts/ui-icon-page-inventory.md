# UI 图标按游戏页面收敛清单

本文是 UI 图标生成前的页面级需求清单，回答“每个游戏页面、每个页面位置到底需要哪些 UI 图标”，并给出 UI 映射、图标 ID、图标主体和简洁提示词。已确认图标的开发入口是 `../ui-icon-final/README.md`；本文件只用于补图、新增图标和追溯生成规则。可复制的图集提示词代码块单独放在 `ui-icon-atlas-prompt-groups.md`。

## 口径

- 每一条图标记录必须落到 `游戏页面 -> 页面位置 -> UI文字/控件 -> 建议图标ID -> 简洁提示词 -> 使用位置`。
- 开发接入已确认图标时，读取 `../ui-icon-final/confirmed-ui-rules.md` 或 `../ui-icon-final/confirmed-ui-rules.csv`；本文件不覆盖确认结果。
- `游戏页面 + 页面位置 + UI文字/控件 + 使用位置` 共同构成生成前 UI 映射，必须能看出该图标对应正式 UI 的哪个入口、组件、状态、命令或内容 ID。
- `建议图标ID` 是生成前稳定 ID；确认后只在 `../ui-icon-final/confirmed-ui-rules.md` 和 `../ui-icon-final/confirmed-ui-rules.csv` 维护。
- `简洁提示词` 只写图标主体元素，保持短句；UI 按钮默认是单独图标内容，不额外画方框、按钮底板或外框，只有清单、卡片、徽章、锁槽、装备槽、弹窗卡等主体本身需要承载形状时才画框；图集坐标只写在 `ui-icon-atlas-prompt-groups.md`。
- 不为省图合并不同 UI 内容；同一 UI 图标多处出现时，只记录使用位置。
- 每张 UI 图集固定 `2048x2048`，最多 `50` 个 UI 图标；每个 UI 图标固定 `128x128`。
- 图集编号从 `UIATLAS_001` 起；每张图集只对应一个模块。
- 每张图集从 `001 icon(416,208,128,128)` 开始，横向步进 144，每行最多 7 个，最多 50 个图标。
- 不是同一模块的 UI 图标不得放在同一张图集；`standalone_25th_hour_icon` 单独生成，不进入任何图集。
- 严格我的世界方块像素风：低色数、硬边像素、深色粗描边；人物头像必须完全正面。
- 图标不可替代文字状态、禁用原因或 delta 文案。
- 底部主入口正式名称固定为：商店购物、竞赛投稿、考研升学、申请保研、考公考编选调、出国留学、实习与工作、转行、结局与成就。
- 右侧正式入口固定为：个人作品集与简历、建筑生的万里路。
