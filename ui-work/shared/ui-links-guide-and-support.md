# 游戏引导、外部链接与支持页面

本文确认游戏引导、BGM 设置、飞书外链入口和“请作者喝咖啡续命”页面。

## BGM 与声音设置

- 音乐系统首版只做表现层，不提供数值加成。
- 开头曲和中间 BGM 不显示歌词。
- 普通结束曲显示歌曲介绍弹窗、舞台内同步歌词字幕和专辑旋转；失败结局绑定曲不显示歌词字幕。
- 设置项保存到 `localStorage`：主音量、音乐音量、音效音量、静音、动效减弱。
- 开头曲在玩家打开网址时尝试立即播放，并继续顺播到正式进入游戏；若浏览器拦截自动播放，UI 提示玩家点击页面后恢复播放。
- 未购买 `音乐会员` 时，学年 BGM 不提供手动切歌；只按该学年的既定顺序自动顺播与循环。
- 购买 `音乐会员` 后，玩家可以手动切到当前学年 BGM 曲单的下一首；不能跨学年选歌，不能影响开头曲、结束曲、失败结局绑定曲或结局曲抽取。
- 进入新学年开始提示页面时，立即切到该学年的第 `1` 首歌；玩家点击 `进入本学年` 后继续沿用该学年曲单。
- 曲目自然切歌、学年切歌和结束曲开始播放统一使用渐入渐出。
- 结束曲播放期间不能手动切歌，无论是否购买 `音乐会员`。
- 页面失焦时首版只暂停动效，不自动降低音量。

## 游戏引导

首版引导目标是让玩家理解“每周 3 次行动”和“进度/质量/状态取舍”，不把玩家推向某条最优路线。

推荐引导结构：

1. 开局档案：解释昵称和大学名称只用于显示，不提供数值加成。
2. 角色选择：解释角色有被动特质、专属技能和初始面板。
3. 第一周行动：提示每周固定 `3` 次行动。
4. 第一次评图前：提示进度回答“有没有做完”，作品质量回答“做得好不好”。
5. 第一次高危状态：提示精力、压力、金钱风险和行动置灰原因。
6. 大五路线入口：不主动弹窗催促，只在玩家打开路线页时展示入口说明。
7. 毕业典礼：不解释规则，只做尾声表现。

引导形式：

- 首次进入关键系统时使用短提示，不连续轰炸。
- 所有提示可跳过。
- 设置页提供“重看游戏引导”入口。
- 规则说明不要写成攻略答案，不展示隐藏成功率、路线考试分数线内部折算或结局读取优先级细节。

## 飞书外链与静态入口

当前实现中，公告使用游戏内静态弹窗；社区系统和作者的话使用配置化飞书外链。外链在 `../../web-app/game/external-links.mjs` 中维护，未填写时入口置灰并提示“链接待填写”。

| 入口 | 当前来源 | 当前状态 | 点击行为 |
|---|---|---|---|
| 公告系统 | 游戏内静态弹窗 | 已接入静态弹窗 | 打开游戏内公告 |
| 社区系统 | `externalLinks.communityFeishuUrl` | 已填写 | 新标签页打开飞书链接 |
| 作者的话 | `externalLinks.authorNoteFeishuUrl` | 已填写 | 新标签页打开飞书链接 |

点击规则：

- 已填写链接：`window.open(url, "_blank", "noopener,noreferrer")`。
- 未填写链接：按钮置灰，不跳转。
- 外链 URL 必须由配置提供，不硬编码在组件里。
- 飞书链接变化不影响存档和规则。

## 请作者喝咖啡续命

“请作者喝咖啡续命”按钮打开游戏内支持页面，不直接跳转外站。

页面内容：

- 标题：`请作者喝咖啡续命`
- 简短文字：`当你在熬夜赶图的时候，作者也在写代码、调Bug。如果这款游戏能让你回忆起曾经的某个美好瞬间，那些无比珍贵的过去——我想，这就是我做这件事情的意义。`
- 微信收款码图片：`/asset-work/assets/images/support/微信支付.png`
- 支付宝收款码图片：`/asset-work/assets/images/support/支付宝支付.png`
- 图片缺失时显示占位状态：`收款码待上传`
- 页面底部保留返回按钮。

交互规则：

- 两张二维码并排展示；移动端上下排列。
- 图片只作为静态资源展示，不上传、不识别、不记录支付状态。
- 不做打赏排行榜，不做支付成功回调。
- 支持页面和支付状态不进入游戏规则状态，不写入 `GameState`。
- 打开支持入口的点击次数可通过成就命令记录，累计点击 `1` 次解锁成长成就 `精神股东`；该记录只统计入口点击，不代表真实支付。
