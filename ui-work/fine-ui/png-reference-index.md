# PNG 参考图索引

最后更新时间：`2026-06-25 +08:00`

## 目的

本文记录 `png-references/` 当前保留 PNG 的用途。PNG 只作为精细 UI 的视觉、布局、层级、状态和资产风格参考，不作为玩法、数值、事件、路线、结算、排行榜或存档规则来源。

已经覆盖完整桌面页面的 PNG 是精细 UI 的强制视觉验收基准。主游戏界面普通周行动必须以 `游戏主要过程的浅色背景页面.png` 和 `游戏主要过程的深色背景页面.png` 为准，开发和补图只能在真实数据长度、响应式换行、可访问性和浏览器渲染差异上做工程适配，不能另起一套主界面布局或视觉风格。

用户已删除的两张图片视为废弃参考，不再纳入索引，也不作为缺失项追补。

## 使用规则

- 文案：PNG 内文案是布局占位，最终文案仍读取文档、配置或 view model。
- 数值：PNG 内数值只用于撑开布局，不进入规则文档。
- 入口：PNG 内出现的入口必须回到 `system-entry-status.md` 和 `systems.entries` 校对。
- 图标：PNG 中的像素图标、角色和场景是视觉语言参考；实现时仍需按可用资产和版权边界落地。
- 主题：深浅图用于确定同一信息架构下的主题 token，不允许只做简单反色。
- 强制对齐：已覆盖完整页面的 PNG 优先级高于抽象文字描述；如果文档描述和 PNG 在布局、密度、层级或视觉语言上冲突，先按 PNG 修正文档，再进入开发。

## 仍需补图但不阻塞当前文档对齐

- 高危主流程状态：用于确认风险横幅、禁用行动和建议下一步。
- 系统入口菜单：用于确认占位、最小版、静态、危险操作的视觉差异。
- 商店面板：用于确认余额、限购、禁用购买和购买反馈。
- 结局页：用于确认结局正文、状态摘要、成就、结束曲和重开入口。
- 手机端入口提示/分享预览：用于后续确认阻塞提示、分享预览和低频信息浏览；不补行动区、状态仪表、日志和角色课程的手机布局。
- 展开音乐播放器：用于确认歌词、播放列表、资源缺失和本地测试入口。

这些补图只服务精细 UI 开发前的视觉确认，不改变已对齐的 VM、command 和系统入口语义。
